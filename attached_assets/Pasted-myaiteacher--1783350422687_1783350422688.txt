myaiteacher-ում ավելացրու տնային աշխատանքի ամբողջական համակարգը:

─────────────────────────────────────────────
1. 📝 ՏՆԱՅԻՆ ԱՇԽԱՏԱՆՔ (Homework)
─────────────────────────────────────────────

- Student Dashboard-ում ավելացնել «Տնային աշխատանք» բաժին
- Ցուցադրել բոլոր տնայինները (ըստ դասերի)
- Յուրաքանչյուր տնայինի կարգավիճակը.
  - 🟡 Սպասում է (Pending)
  - 🟢 Գնահատված (Graded)
  - 🔴 Չի ներկայացվել (Not Submitted)

─────────────────────────────────────────────
2. 📋 ՏՆԱՅԻՆԻ ՄԱՆՐԱՄԱՍՆԵՐ
─────────────────────────────────────────────

- Տնայինի վերնագիր
- Առարկա + Դաս
- Հանձնարարություն (առաջադրանք)
- Աշակերտի պատասխանը
- Գնահատական (եթե գնահատված է)
- Ուսուցչի արձագանքը (եթե կա)
- Ներկայացման ամսաթիվ

─────────────────────────────────────────────
3. 📤 ՆԵՐԿԱՅԱՑՆԵԼ ՏՆԱՅԻՆԸ
─────────────────────────────────────────────

- [Ներկայացնել] կոճակ յուրաքանչյուր տնայինի համար
- Տեքստային դաշտ (պատասխան)
- Ֆայլ կցելու հնարավորություն (ըստ ցանկության)
- Ներկայացնելուց հետո կարգավիճակը դառնում է «Սպասում է»

─────────────────────────────────────────────
4. 🧠 AI-Ի ՄԻՋՈՑՈՎ ԳՆԱՀԱՏՈՒՄ
─────────────────────────────────────────────

- Ուսուցիչը կարող է գնահատել տնայինը
- AI-ն առաջարկում է գնահատական (ըստ ցանկության)
- [Գնահատել] կոճակ (ուսուցչի համար)
- Գնահատական (0-100)
- Արձագանք (տեքստային)

─────────────────────────────────────────────
5. API
─────────────────────────────────────────────

- GET /api/homework — բոլոր տնայինները
- GET /api/homework/:id — կոնկրետ տնային
- POST /api/homework/:id/submit — ներկայացնել
- POST /api/homework/:id/grade — գնահատել (ուսուցիչ)

─────────────────────────────────────────────
6. FRONTEND
─────────────────────────────────────────────

- homework.html (կամ Homework.jsx)
- Ցուցակ (բոլոր տնայինները)
- Մանրամասն էջ (յուրաքանչյուր տնայինի համար)
- [Ներկայացնել] ձև (տեքստ + ֆայլ)
- [Գնահատել] ձև (ուսուցչի համար)

─────────────────────────────────────────────
7. DATABASE
─────────────────────────────────────────────

- homework աղյուսակ (id, student_id, lesson_id, task, answer, score, feedback, status, submitted_at, graded_at)

─────────────────────────────────────────────
8. 📌 ՊԱՀԱՆՋՆԵՐ
─────────────────────────────────────────────

- Տնայինները ավտոմատ ստեղծվում են դասի ավարտին (8-րդ փուլ)
- 3 մակարդակ (Թույլ, Միջին, Ուժեղ)
- Աշակերտը կարող է ներկայացնել միայն մեկ անգամ
- Ուսուցիչը կարող է գնահատել և արձագանքել

─────────────────────────────────────────────
9. 🚀 ՏՐԱՄԱԴՐԻՐ ԱՄԲՈՂՋԱԿԱՆ ԿՈԴԸ
─────────────────────────────────────────────

- Backend (homework routes, grading logic)
- Frontend (homework.html, submit.html, grade.html)
- Database (homework աղյուսակ)
- AI-ի ինտեգրում (գնահատման առաջարկ)
