8. PERFORMANCE OBJECTIVE PER LEVEL
==================================================

Each level must have a distinct, observable learner performance.

Bad progression:

REMEMBER:
"know the rule"

UNDERSTAND:
"understand the rule"

APPLY:
"apply the rule"

Good progression:

"Recall that a function zero satisfies f(a)=0."

UNDERSTAND:
"Explain why zeros correspond to x-axis intersections."

APPLY:
"Determine the zeros of a new function graph."

Each level must add a real cognitive capability.
