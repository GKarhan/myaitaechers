════════════════════════════════════════════════════════════
4. NON-NEGOTIABLE TARGET CONTRACT
════════════════════════════════════════════════════════════

An IndependentLearningTarget must represent:

ONE source-supported,
meaningful,
independently assessable learner capability/state.

A target should normally exist when:

1. SOURCE SUPPORT
There is verified instructional source evidence.

2. LEARNER PERFORMANCE
There is a meaningful thing the learner can know, interpret, determine,
construct, explain, classify, compare, solve, or otherwise demonstrate.

3. INDEPENDENT ASSESSABILITY
Mastery can be reasonably tested separately from related targets.

4. ATOMICITY
The target is one coherent learner state, not several independent states bundled.

5. CURRICULUM RELEVANCE
The target is part of what the lesson actually teaches, not merely page furniture,
example wording, or incidental context.

6. NON-DUPLICATION
It is not simply another wording/Bloom-level representation of the same target.

════════════════════════════════════════════════════════════
5. MULTI-SIGNAL TARGET DISCOVERY
════════════════════════════════════════════════════════════

Target discovery must NOT depend on a single source.

Use multiple evidence channels:

A. VERIFIED INSTRUCTIONAL SOURCE
- definitions
- rules
- explanations
- procedures
- transformations
- representations
- instructional worked examples

B. EXERCISE / TASK DEMAND
Exercises reveal what the learner is expected to perform.

C. LESSON OUTCOMES
Saved source-grounded outcomes are curriculum signals.

D. LESSON GOAL
May provide broad intent but is weaker than direct source evidence.

E. GENERATED CANDIDATES
Existing KnowledgeCandidates remain valuable evidence.

No single channel should automatically create a target by itself in all cases.

Use evidence combination.

════════════════════════════════════════════════════════════
6. EXERCISES ARE SIGNALS, NOT AUTOMATIC TARGETS
════════════════════════════════════════════════════════════

Preserve the existing invariant:

EXERCISE ≠ MICRONODE
EXERCISE ≠ AUTOMATIC KNOWLEDGE TARGET

However, a CLUSTER of exercises can strongly support the existence of an
independently assessable target when combined with source evidence.

Example:

source teaches:
“given sign intervals, construct a possible function graph”

and six exercises independently require that transformation.

This is strong evidence for a target.

But:

one unusual exercise with no corresponding instructional source
must NOT automatically create a new target.

Target discovery should require source grounding or explicit review.

7. OUTCOMES ARE SIGNALS, NOT ONE-TO-ONE TARGETS
════════════════════════════════════════════════════════════

Do NOT create one target per saved outcome.

Outcomes may be:

- overlapping

- teacher-authored drafts

But outcomes must contribute to target discovery.

If an outcome describes an independently assessable transformation and source
evidence supports it, it should help establish/confirm the target.

Outcome semantics must include required learner PERFORMANCE, not only shared
concept words.

Current job 177 incorrectly aligned:

════════════════════════════════════════════════════════════
8. PERFORMANCE-DIRECTION SEMANTICS
════════════════════════════════════════════════════════════

Target identity must preserve learner-performance direction.

The system must distinguish transformations such as:

A → B

versus

B → A

when mastery can diverge.

Examples:

graph → determine intervals
intervals → construct graph

text → classify grammatical property
properties → produce/identify matching example

observation → infer cause
conditions → predict observation

data → calculate result
result/constraint → construct representation

Do NOT hardcode “inverse always separate”.

Use independent assessability.

If learner evidence for A does not prove B, they are separate targets.
