### Քայլ 1 — DB-ից վերցրու Lesson 104-ի ամբողջ exercise inventory-ն

Query արա `lesson_exercises`-ը `lesson_id = 104`-ով և յուրաքանչյուր row-ի համար ցույց տուր՝

* id
* source_block_index
* related_node_id
* assignment
* exercise_text_verbatim-ի կարճ preview
* lesson_id

Հստակ բաժանիր՝

A. mapped exercises (`relatedNodeId != null`)
B. unassigned/additional exercises (`relatedNodeId == null`)

Չփոխես DB-ի ոչ մի տվյալ։

### Քայլ 2 — կարդա chat.ts-ի իրական handoff logic-ը

Գտիր այն exact query/code path-ը, որով AI Teacher-ի node session-ի ժամանակ `classExercises`, `homeworkExercises`, `DEEP_DIVE_EXERCISES` և այլն կառուցվում են։

Պարզիր՝

* ինչ WHERE պայմաններով են exercises-ը վերցվում,
* արդյոք `relatedNodeId = null` exercises-ը երբևէ մտնում են lessonContext,
* եթե այո՝ կոնկրետ որ context block-ի մեջ,
* եթե ոչ՝ կոնկրետ որտեղ են դուրս մնում։

Մի ենթադրիր։ Ցույց տուր exact code evidence-ը։

### Քայլ 3 — իրական Lesson 104 teaching session բացիր

Օգտագործիր Lesson 104-ի իրական ուսուցման flow-ը։
