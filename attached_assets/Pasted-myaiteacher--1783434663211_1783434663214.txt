8. API
─────────────────────────────────────────────

- GET /api/teacher/classes — ուսուցչի դասարանները
- GET /api/teacher/class/:id — դասարանի տվյալները
- GET /api/teacher/courses/:class_id — դասընթացների ցանկը
- GET /api/teacher/course/:id — դասընթացի տվյալները
- POST /api/teacher/course/resources — կցել ռեսուրս (գիրք, ծրագիր, պլան)
- POST /api/teacher/course/generate-lessons — AI-ով դասեր գեներացնել
- POST /api/teacher/course/lesson — ձեռքով դաս ավելացնել
- PUT /api/teacher/course/lesson/:id — խմբագրել դաս
- DELETE /api/teacher/course/lesson/:id — ջնջել դաս
