# PART 5 — Քայլ 3. Provisional mastery

PART 4-ը ցույց տվեց.

`2/2 correct → mastery=100 → mastered`

Սա ներկայիս scoring-ի տրամաբանությամբ տեխնիկապես հնարավոր է, բայց pedagogically չափազանց ուժեղ եզրակացություն է։

Ուստի ուսումնասիրիր՝ ինչպես կարելի է օգտագործել արդեն գոյություն ունեցող.

`is_provisional`

դաշտը՝ առանց ամբողջ mastery համակարգը վերակառուցելու։

Առաջարկիր հստակ rule set, օրինակ՝

* initial quiz evidence → provisional
* repeated evidence / later validation → verified
* verified mastery → իրական mastered state

Բայց **ինքնուրույն մի ընտրիր threshold-ը**։

Նախ ցույց տուր.

1. ներկայիս behavior-ը
2. առաջարկվող behavior-ը
3. ինչ database/code changes են անհրաժեշտ
4. ինչ regressions կարող են առաջանալ
