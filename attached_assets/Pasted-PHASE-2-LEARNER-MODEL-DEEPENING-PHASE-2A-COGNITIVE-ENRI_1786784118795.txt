curriculum content, source exercises/tasks, and the type of knowledge/skill

============================================================
6. TARGET COGNITIVE CEILING
============================================================

The AI must explicitly determine the highest justified cognitive level.

The ceiling must be based on what the curriculum expects from THIS MicroNode.

Examples:

Definition/recognition:
remember → understand

Conceptual understanding:
remember → understand

Procedural use:
remember → understand → apply

Comparison/relationship reasoning:
understand → apply → analyze

Judgment with criteria:
understand → apply → analyze → evaluate

Production/design:
understand → apply → analyze → evaluate → create

These are GUIDES, not mechanical rules.

The source learning objective and tasks have priority.

============================================================
7. PERFORMANCE OBJECTIVE
============================================================

Every applicable cognitive level needs an observable performance objective.

Bad:

"Հասկանալ մոլեկուլները։"

Good:

"Սովորողը կարող է սեփական բառերով բացատրել, թե ինչ է մոլեկուլը և
տարբերակել այն ատոմից։"

For Apply:

"Սովորողը կարող է նոր օրինակում կիրառել ատոմի և մոլեկուլի
տարբերակման սկզբունքը։"

Objectives must describe observable learner performance.

============================================================
8. SUCCESS CRITERION
============================================================

Every cognitive level must have a success criterion.

Example:

REMEMBER
Performance objective:
Սովորողը կարող է ճանաչել և անվանել հասկացությունը։

Success criterion:
Ճիշտ է ճանաչում/ընտրում հասկացությունը անկախ օրինակներում։

UNDERSTAND
Performance objective:
Սովորողը կարող է բացատրել հասկացության իմաստը։

Success criterion:
Ճիշտ բացատրում կամ դասակարգում է հասկացությունը նոր ձևակերպմամբ։

APPLY
Performance objective:
Սովորողը կարող է կիրառել հասկացությունը նոր իրավիճակում։

Success criterion:
Ճիշտ լուծում կամ ընտրում է առնվազն պահանջվող անկախ կիրառական
առաջադրանքները։

============================================================
13. INDEPENDENT PROBLEM SOLVING
============================================================

The model/UI must support the future case where:

1. learner independently solves a problem;
2. learner does NOT need to type the whole reasoning unless required;
3. learner may:
   - enter final answer, or
   - select the correct final answer;
4. the task still counts as Apply/Analyze if its actual cognitive demand
   justifies that classification.

DO NOT equate:

multiple choice = Remember

or

written response = higher-order thinking.

Interaction format and cognitive demand are separate.

============================================================
14. BLOOM ≠ DIFFICULTY ≠ INTERACTION
============================================================

Maintain three separate dimensions:

Cognitive demand:
remember / understand / apply / analyze / evaluate / create

Difficulty:
LOW / MEDIUM / HIGH or canonical repository equivalent

Interaction:
multiple_choice / matching / numeric_answer / short_answer / etc.

Never infer one directly from another.
