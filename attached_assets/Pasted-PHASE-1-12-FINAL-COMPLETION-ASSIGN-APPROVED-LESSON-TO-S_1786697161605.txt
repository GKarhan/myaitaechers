10. CRITICAL TEST MODEL
LINKED ≠ RELEASED
==================================================

This rule is mandatory.

A Quiz linked to a Lesson is NOT automatically available to solve.

These are two separate relationships:

QUIZ ↔ LESSON
means:
"This test belongs to this Lesson."

QUIZ ↔ STUDENT ASSIGNMENT/RELEASE
means:
"This student is allowed to solve this test now."

Example:

Lesson A has:

Test 1
Test 2
Test 3

Student receives Lesson A.

Expected initial state:

Test 1 — linked, unreleased
Test 2 — linked, unreleased
Test 3 — linked, unreleased

Teacher later releases only Test 2.

Expected:

Test 1 — locked
Test 2 — startable
Test 3 — locked

Do NOT auto-release all linked tests when Lesson is assigned.
