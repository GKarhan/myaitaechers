- "շարունակենք հաջորդ դասը"

even when the lesson state shows:
- current node is not completed

Step 3/5

But AI generated:
"Հիմա կարող ենք անցնել հաջորդ թեմային"

Find the existing node lock / transition validation logic.

1. Where node transition permission is calculated.

3. Where generated AI text can bypass the state machine.

Then implement a guard.

Requirements:
- AI must not announce moving to another topic unless the backend state allows transition.
- The check must not rely only on node_decision.

Add a validation layer similar to validateNodeLock.

PART 2 — Add partial correctness evaluation

Current problem:
Student answers are evaluated too binary:
CORRECT / INCORRECT

Example:
Student:
"հարյուրավորների կարգում է կարգային միավորը 403"

Actual:
- identifying the place value is correct
- the numeric value is wrong

The AI should not mark the whole answer wrong.

Audit current structured response schema.

Find:
- answer evaluation fields
- correctness calculation
- scoring logic

Add support for:

CORRECT
PARTIALLY_CORRECT
INCORRECT

The structured output should include something like:

{
  "answer_evaluation": {
    "status": "PARTIALLY_CORRECT",
    "correct_parts": [],
    "incorrect_parts": []
  }
}

Rules:
- If the student demonstrates the correct concept but has a small mistake, return PARTIALLY_CORRECT.
- Feedback should acknowledge the correct part first.
- Then explain only the mistake.
- Do not lower confidence excessively for partially correct answers.
