Goal:

==================================================
CANONICAL PRODUCT RULE
==================================================

For normal assessment:

MicroNode
→ accepted Cognitive Path
→ exactly one target Cognitive Level
→ assess ONLY that target level.

Examples:

Understand
→ assess Understand

Apply
→ assess Apply

Understand → Apply
→ assess Apply

Remember → Understand → Apply
→ assess Apply

Understand → Apply → Analyze
→ assess Analyze

Lower Cognitive Path levels are NOT separate normal-quiz targets.

They remain part of the AI Teacher instructional/remediation path.

==================================================
CANONICAL TARGET SOURCE
==================================================

The canonical target source is:

lesson_node_cognitive_levels.isTargetCeiling

Do NOT infer the assessment target from:

- lesson_nodes.targetBloomLevel
- highest sequence alone
- highest Bloom level alone
- provider judgment
- difficultyMode

targetBloomLevel remains compatibility/derived data.

==================================================
REQUIRED VALIDATION
==================================================

A valid target requires:

1. Cognitive Path is confirmed/accepted.
2. At least one applicable level exists.
3. Exactly one applicable isTargetCeiling=true level exists.
4. Target level is applicable.
5. Target is the final ordered applicable level.
6. Cognitive levels progress in valid increasing cognitive order.
7. Sequences are structurally valid.
8. Existing grounding/acceptance requirements pass.
9. Required target fields satisfy the existing accepted-path contract.

Do not silently repair invalid data.
