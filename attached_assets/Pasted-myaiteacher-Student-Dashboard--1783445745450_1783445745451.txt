myaiteacher-ում աշակերտի գլխավոր էջը (Student Dashboard) կարգավորել հետևյալ կերպ.

─────────────────────────────────────────────
1. 🏷️ ՈՒՂՂԵԼ ՏԵՔՍՏԵՐԸ (ՀԱՅԵՐԵՆ)
─────────────────────────────────────────────

- "Ենդհանուր 🏠" → "Ընդհանուր"
- "Ա՜արկաներ 📚" → "Առարկաներ"
- "Արաջնթհաց" → "Առաջընթաց"
- "Այսորի իմ Դասերը" → "Այսօրվա իմ դասերը"
- "Այսոր Դասեր չկան" → "Այսօր դասեր չկան"
- "Անձnakan" → "Անձնական տվյալներ"

─────────────────────────────────────────────
2. ❌ ՀԵՌԱՑՆԵԼ ԱՎԵԼՈՐԴ ԲԱԺԻՆՆԵՐԸ
─────────────────────────────────────────────

- 📊 Վիճակագրություն (Ավարտված դասեր, Միջին գնահատական, Չներկայացված, Առաջընթաց)
- 📊 Առաջընթաց (progress bar)
- 🤖 AI Chat ([Բացել AI Chat] կոճակ)
- 🗺️ Գիտելիքի քարտեզ (թեմաներ + [Սովորել] / [Կրկնել])
- 🏠 Տնային (քանի որ դեռ չկա)

─────────────────────────────────────────────
3. ✅ ԹՈՂՆԵԼ ԵՎ ՊԱՀՊԱՆԵԼ
─────────────────────────────────────────────

- 👋 "Բարի գալուստ, [Աշակերտի Անուն Ազգանուն]" (օր. "Բարի գալուստ, Էլեն Քարհանյան")
- 📅 Դասացուցակ — այսօրվա դասերը (ժամ, առարկա)
  - [Սովորել] կոճակ → տանում է դասի էջ (AI-ն սկսում է)
  - Եթե դասեր չկան → "Այսօր դասեր չկան"
- 📚 Առարկաներ — աշակերտի բոլոր առարկաները (ըստ ուսուցչի ավելացրածի)
  - Առարկայի անուն, առաջընթաց (%)
  - [Դիտել] կոճակ → տանում է առարկայի էջ
- 👨‍🏫 Ուսուցիչներ — ցուցակ (անուն, ազգանուն, առարկա, դասարան)
  - Օրինակ՝ "Լաուրա Քարհանյան  📚 Հանրահաշիվ · 7"
- 📋 Անձնական տվյալներ — (կարող է մնալ)

─────────────────────────────────────────────
4. 🔄 ԴԻՆԱՄԻԿ ԲՈՎԱՆԴԱԿՈՒԹՅՈՒՆ
─────────────────────────────────────────────

- Առարկաները ավտոմատ բերվում են ուսուցչի կողմից ավելացվածից
- Դասացուցակը ավտոմատ բերվում է ադմինի կողմից ստեղծվածից
- Ուսուցիչները ավտոմատ բերվում են ադմինի կողմից կցվածից
- Ապագայում ավելացվող առարկաները ավտոմատ երևան

─────────────────────────────────────────────
5. 🧭 ՆԱՎԻԳԱՑԻԱ
─────────────────────────────────────────────

- "Դասացուցակ 📅" → ցույց է տալիս դասացուցակը
- "Առարկաներ 📚" → ցույց է տալիս առարկաները
- "Ուսուցիչներ 👨‍🏫" → ցույց է տալիս ուսուցիչներին
- "Անձնական 📋" → ցույց է տալիս անձնական տվյալները

─────────────────────────────────────────────
6. 📌 ԿԱՐԵՎՈՐ
─────────────────────────────────────────────

- Բոլոր տերմինները հայերեն են
- [Սովորել] → տանում է դասի էջ
- [Դիտել] → տանում է առարկայի էջ
- Առաջընթացը, AI Chat-ը, Գիտելիքի քարտեզը, Տնայինը կլինեն համապատասխան էջերում (դասի, առարկայի)

─────────────────────────────────────────────
7. 🚀 ՏՐԱՄԱԴՐԻՐ ԱՄԲՈՂՋԱԿԱՆ ԿՈԴԸ
─────────────────────────────────────────────

- Frontend (student.html)
- Backend (student routes — dashboard, subjects, schedule, teachers)
- Database (students, classes, schedule, courses, lessons)
- Բոլոր փոփոխությունները ներդրված են
- OpenRouter-ի ինտեգրումը պահպանված է
