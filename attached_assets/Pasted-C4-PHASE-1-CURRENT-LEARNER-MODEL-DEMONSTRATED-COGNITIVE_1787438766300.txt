==================================================
CORE ARCHITECTURAL RULE
==================================================

DO NOT confuse:

A) CURRICULUM TARGET COGNITIVE LEVEL
"What level should this MicroNode ultimately reach?"

with

B) LEARNER CURRENT DEMONSTRATED COGNITIVE CEILING
"What is the highest cognitive level this learner has actually
demonstrated with sufficient qualifying evidence?"

These are different concepts.

Curriculum target:
MicroNode/C2 property.

Demonstrated ceiling:
learner × MicroNode property.

The learner must NEVER be promoted to a cognitive level merely because
that level exists in the Cognitive Path.
