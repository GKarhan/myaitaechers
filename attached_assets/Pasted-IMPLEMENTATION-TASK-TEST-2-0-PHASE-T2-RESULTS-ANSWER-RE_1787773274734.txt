IMPLEMENTATION TASK — TEST 2.0 / PHASE T2
RESULTS → ANSWER REVIEW → CANONICAL RETEST CHOICE

GOAL

Build the learner-facing Results/Review/Choice step for Test 2.0.

T1 is already complete and established the canonical backend-owned retest authority.

T2 must expose that authority safely in the completed-quiz Results experience.

The learner should:

1. complete the quiz using the existing flow;
2. see the existing quiz result;
3. review the questions and answers;
4. clearly see incorrect answers and the existing short feedback/explanations;
5. see what canonical retest options are currently available;
6. choose a next action.

IMPORTANT:

T2 DOES NOT CREATE A NEW QUIZ YET.

Automatic targeted retest creation belongs to T3.

This task is primarily:

RESULTS
→ REVIEW
→ CANONICAL RETEST OPTIONS
→ USER CHOICE

Do not implement the next quiz generation.

2. DESIRED LEARNER FLOW
==================================================

After successful final quiz submission:

CURRENT QUIZ COMPLETION
→ RESULTS
→ ANSWER REVIEW
→ RETEST CHOICE

The learner should be able to understand:

1. How did I do?
2. Which questions were correct?
3. Which questions were incorrect?
4. What was my answer?

6. Why was the correct answer correct?

8. What can I do next?

Keep this lightweight.

9. IMPORTANT OVERLAP RULE
==================================================

PARTIAL_AND_NOT_KNOWN includes:

PARTIAL + NOT_KNOWN.

NOT_KNOWN_ONLY is therefore a subset.

NOT_KNOWN_ONLY = 2

Do NOT display this as 7 total weak nodes.
