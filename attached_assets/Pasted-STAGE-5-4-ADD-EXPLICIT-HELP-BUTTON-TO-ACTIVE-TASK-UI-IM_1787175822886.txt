==================================================
GOAL
==================================================

When a learner has a real active answerable task, show a visible:

💡 Հուշում

button/action.

The learner should not need to type:

- հուշիր
- օգնիր
- չգիտեմ, հուշե՞ս

The existing text-based HELP recognition remains as fallback.

==================================================
REQUIRED FLOW
==================================================

ACTIVE TASK
→ learner clicks [💡 Հուշում]
→ frontend sends explicit HELP action/request
→ existing authoritative executeHelpRequest(...) flow
→ help_events persisted
→ activeHelpCount +1
→ activeAssistanceLevel updated
→ bounded learner-safe hint generated
→ same active task remains active
→ learner answers normally

The HELP button must NOT:

- create evidence
- evaluate the answer
- advance mastery
- change cognitive level
- change task identity
- generate a new task
- send a fake learner chat message like "հուշիր"

==================================================
UI RULE
==================================================

Show the button only when a real active learner-answerable task exists.

Examples:

- active source exercise → show
- active generated MICRO_CHECK → show
- no active task → hide
- THEORY only → hide
- FEEDBACK only → hide
- completed node → hide

Use current authoritative task state from the existing API/session data.

Do not infer task activity from visible text.

==================================================
FRONTEND BEHAVIOR
==================================================

On click:

1. disable the button while request is pending
2. call the existing HELP endpoint/action directly
3. render the returned assistant hint
4. keep the current task visible and active
5. re-enable according to current help policy/state

Do not locally increment help count.
Backend remains authority.

Do not locally synthesize hint text.

==================================================
LABEL
==================================================

Use Armenian learner-facing label:

💡 Հուշում

Optional tooltip/subtext if the existing UI pattern supports it:

«Ստանալ փոքր հուշում»

Keep it compact.

==================================================
HELP COUNT / LIMIT
==================================================

If the backend currently exposes enough state to know HELP availability or
limit, respect it.

Do not invent a frontend-only help limit.

If the backend rejects further HELP according to current policy:
→ show the existing safe backend response/state
→ do not bypass it.
