GOAL

Before rebuilding the quiz system, fully document the CURRENT end-to-end quiz architecture and determine exactly what can be preserved for Test 2.0 v1.

The target Test 2.0 v1 is intentionally simple:

Teacher creates quiz
→ Student completes quiz
→ Results + existing feedback
→ Student sees:
   - Գիտի
   - Մասնակի գիտի
   - Չգիտի
→ Student reviews wrong answers
→ Student chooses:
   A. Retest Մասնակի + Չգիտի
   B. Retest only Չգիտի
   C. Stop
→ System automatically creates a new quiz from those MicroNodes
→ Student completes next round
→ Results update
→ Knowledge Tree updates
→ Student may repeat again or stop

For feedback, DO NOT redesign anything yet.

Current desired feedback is simply:
- student answer
- correct answer
- one short explanation why correct
- one short explanation why student's answer is wrong

If current system already does this adequately, preserve it.
