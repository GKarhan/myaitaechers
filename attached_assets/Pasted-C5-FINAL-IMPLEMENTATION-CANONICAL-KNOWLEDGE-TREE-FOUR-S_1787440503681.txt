4. CANONICAL CLASSIFICATION RULE
════════════════════════════════════════════════════

Implement this rule unless actual schema constraints require the
smallest equivalent safe adaptation.

────────────────────────────────────────
A. NOT_STUDIED — Դեռ չի ուսումնասիրել
────────────────────────────────────────

Meaning:

There is NO meaningful learner attempt/interaction/evidence for this
MicroNode.

Do NOT define NOT_STUDIED merely as:

knowledge_nodes row absent

or:

mastery_score == null && confidence_score == null.

A learner may have attempted the MicroNode and still have no score.

────────────────────────────────────────
B. NOT_KNOWN — Չգիտի
────────────────────────────────────────

Meaning:

A meaningful learner attempt exists,

BUT

no accepted Cognitive Level has been sufficiently demonstrated by C4.

Typical canonical condition:

meaningfulAttempt == true
AND
demonstrated_cognitive_level_id == null

This state means:

studied/attempted
but insufficient knowledge demonstrated.

────────────────────────────────────────
C. PARTIAL — Մասնակի գիտի
────────────────────────────────────────

Meaning:

C4 has a valid demonstrated Cognitive Level,

BUT

the learner has not yet reached the MicroNode's C2 curriculum target.

Compare using the ACCEPTED C2 PATH ORDER.

Do NOT compare raw Bloom numbers blindly.

Example:

Accepted path:

REMEMBER
→ UNDERSTAND
→ APPLY
→ ANALYZE(target)

Demonstrated = UNDERSTAND

Result:

PARTIAL

Demonstrated = APPLY

Result:

PARTIAL

But preserve the demonstrated ID so these two learner states remain
cognitively distinguishable even though both render as:

Մասնակի գիտի

────────────────────────────────────────
D. MASTERED — Գիտի
────────────────────────────────────────

Meaning:

C4 demonstrated ceiling has reached the MicroNode's C2 curriculum target.

Use accepted C2 path identity/order.

Canonical condition conceptually:

demonstrated path position >= target path position

Because C4 is contiguous and monotonic, reaching target means the
required accepted path through target has been demonstrated.

MASTERED MUST NOT be granted merely because:

mastery >= 80
confidence >= 50

or another legacy score threshold passes.

5. C2 PATH SAFETY
════════════════════════════════════════════════════

DO NOT assume Cognitive Paths always start at REMEMBER.

DO NOT compare raw Bloom numeric values as the authoritative rule.

Use accepted C2 Cognitive Path:

If target and demonstrated IDs belong to the accepted path:

NOT_STUDIED.
