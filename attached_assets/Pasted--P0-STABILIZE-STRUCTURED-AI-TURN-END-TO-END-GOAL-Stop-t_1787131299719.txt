Apply the smallest robust fix.

> If the backend already knows a value deterministically, do not require the model to guess it merely to satisfy the schema.

> Fields that are meaningful only for certain response types should not unnecessarily invalidate unrelated turns.

However, do NOT weaken important teaching/state guarantees.

* root structured object
* valid teaching_mode

* interaction_type must match active Cognitive Path

* answer/evidence rules when evaluating an answer
* source exercise identity when a real source exercise is active

Use conditional validation where appropriate rather than making every field universally fragile.
