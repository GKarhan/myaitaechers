════════════════════════════════════════════════════
6. FIX B — STRONGER DIRECT SOURCE SUPPORT
════════════════════════════════════════════════════

Strengthen source grounding without pretending deterministic lexical code
can perfectly understand pedagogy.

The system must distinguish:

1. DIRECT SUPPORT

The source actually teaches, states, explains, defines, demonstrates, or
establishes the MicroNode objective.

2. SUPPORTING CONTEXT

The source is relevant/motivational/contextual but does not independently
establish the objective.

3. INSUFFICIENT

The source shares topic words but does not teach the claimed objective.

4. UNREADABLE

Cannot serve as authority.

Do NOT treat:

two shared concept words

as sufficient final proof by itself.

════════════════════════════════════════════════════

════════════════════════════════════════════════════

SOURCE_SUPPORT = SUFFICIENT

Use the current architecture's safest bounded combination of:

- objective concept structure
- owned validated source
- source block type/function
- direct rule/explanation/definition evidence
- bounded semantic review if needed
- Fix #6A same-lesson reallocation evidence

Lexical normalization may identify candidate support.

Lexical matching MUST NOT alone be final authority.
