myaiteacher-ում ավելացրու առաջընթացի ամբողջական համակարգը և ընդհանուր գիտելիքի քարտեզը:

─────────────────────────────────────────────
1. 📊 ԱՌԱՋԸՆԹԱՑ (Progress)
─────────────────────────────────────────────

- Student Dashboard-ում ավելացնել «Առաջընթաց» բաժին
- Ցուցադրել.
  - Ընդհանուր առաջընթաց (%)
  - Միջին գնահատական
  - Յուրացման մակարդակ (%)
  - Ավարտված դասեր
  - Ակտիվ դասեր
  - Վերջին ակտիվությունը

─────────────────────────────────────────────
2. 🗺️ ԸՆԴՀԱՆՈՒՐ ԳԻՏԵԼԻՔԻ ՔԱՐՏԵԶ (Knowledge Map)
─────────────────────────────────────────────

- Բոլոր առարկաների ամփոփ ցուցակը
- Գունավորում.
  🟢 ≥80% → "Յուրացված"
  🟡 50-79% → "Թույլ"
  🔴 <50% → "Չսկսված"

- Յուրաքանչյուր առարկայի համար.
  - Անուն
  - Առաջընթաց (%)
  - Ավարտված դասեր / Ընդհանուր դասեր
  - [Մանրամասն] կոճակ (տանում է Subject Detail)

─────────────────────────────────────────────
3. 📈 ԹԵՄԱՅԻ ՄԱՆՐԱՄԱՍՆ ԱՌԱՋԸՆԹԱՑ
─────────────────────────────────────────────

- Յուրաքանչյուր թեմայի համար.
  - Անուն
  - Առաջընթաց (%)
  - Վերջին թեստի արդյունքը
  - Փորձերի քանակը
  - Սխալներ (ցուցակ)
  - [Կրկնել] / [Սովորել] կոճակներ

─────────────────────────────────────────────
4. 🤖 AI-Ի ԱՌԱՋԱՐԿՈՒԹՅՈՒՆՆԵՐ
─────────────────────────────────────────────

- AI-ն վերլուծում է առաջընթացը
- Տալիս է խորհուրդներ.
  - "Սկսեք [թեմայից]" 
  - "Կրկնեք [թեման]"
  - "Դուք պատրաստ եք հաջորդ դասին"

─────────────────────────────────────────────
5. API
─────────────────────────────────────────────

- GET /api/progress — ընդհանուր առաջընթաց
- GET /api/progress/subject/:id — առարկայի առաջընթաց
- GET /api/progress/topic/:id — թեմայի առաջընթաց
- GET /api/progress/recommendations — AI-ի առաջարկություններ

─────────────────────────────────────────────
6. FRONTEND
─────────────────────────────────────────────

- progress.html (կամ Progress.jsx)
- knowledge-map.html (կամ KnowledgeMap.jsx)
- topic-detail.html (կամ TopicDetail.jsx)

─────────────────────────────────────────────
7. DATABASE
─────────────────────────────────────────────

- progress աղյուսակ (id, student_id, subject_id, lesson_id, score, status, attempts, mistakes, last_activity)

─────────────────────────────────────────────
8. 📌 ՊԱՀԱՆՋՆԵՐ
─────────────────────────────────────────────

- Բոլոր առարկաների ամփոփ ցուցակը
- Թեմաների մանրամասն առաջընթացը
- AI-ի առաջարկությունները
- Ֆիլտրեր (All / Mastered / Review / Not Started)

─────────────────────────────────────────────
9. 🚀 ՏՐԱՄԱԴՐԻՐ ԱՄԲՈՂՋԱԿԱՆ ԿՈԴԸ
─────────────────────────────────────────────

- Backend (progress routes, AI recommendations)
- Frontend (progress.html, knowledge-map.html, topic-detail.html)
- Database (progress աղյուսակ)
- AI-ի ինտեգրում (առաջարկությունների համար)
