# UI LOCALIZATION CLEANUP — FINAL ARMENIAN TEXT

## Նպատակ

Իրական թեստը ֆունկցիոնալ առումով ճիշտ է աշխատում։

**Չփոխել ոչ մի ֆունկցիոնալ logic։**

Պետք է կատարել միայն quiz result էջի **UI text localization cleanup**՝ բոլոր խառը, ռոմանիզացված, սխալ encoding-ով կամ ոչ բնական հայերեն display string-երը դարձնելով գրագետ արևելահայերեն։

---

# ABSOLUTE RULE

Մի փոխիր՝

* quiz logic
* question generation logic
* answer evaluation
* scoring
* mastery calculation
* confidence calculation
* evidence events
* Knowledge Tree
* recommendations logic
* API contract
* database schema
* database data
* `option_explanations`
* feedback generation logic
* node mapping

**Միայն display/UI text localization։**

```text

Ինչպե՞ս է գրվում մեկ միլիոնը:

Ի՞նչ է ցույց տալիս միլիոնների դասում գրված թիվը:

25 435 234 թիվը ի՞նչ դասի է պատկանում 435 մասը:

Ինչպե՞ս են կարդում բազմանիշ թիվը:

Ի՞նչ է ցույց տալիս թվի գրության յուրաքանչյուր թվանշան:

3426 թվի III կարգում քանի՞ հատ 100 կա:

Եթե թվի I դասում գրված է 789, ի՞նչ է սա նշանակում:

Թիվը կարդալիս ի՞նչ հաջորդականությամբ են ավելացնում դասի անվանումը:
```

# 20. FEEDBACK TEXT

Feedback-ի իրական բովանդակությունը **չփոխել ձեռքով**։

Օրինակ՝

```text
Ճիշտ է, քանի որ յուրաքանչյուր երեք հաջորդական կարգ կազմում է մեկ դաս:
```

կամ

```text
Սխալ է, քանի որ միլիոնների դասում 25-ն է:
```

Սրանք պետք չէ hardcode անել կամ փոխարինել։

Պետք է միայն համոզվել, որ **UI label-ը**, որը feedback-ի վերևում է, հայերեն է.

```text

```

կամ

```text
Ինչու է սխալ
```
