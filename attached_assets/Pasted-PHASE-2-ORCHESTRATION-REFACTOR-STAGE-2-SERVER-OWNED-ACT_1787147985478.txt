==================================================

- DELIVER_THEORY
- DELIVER_MICRO_CHECK
- EVALUATE_ACTIVE_TASK

- REMEDIATE
- DELIVER_SOURCE_EXERCISE

- required server state
- whether AI generation is needed
- whether an active task may be created
- whether evaluation is expected
- whether progression may occur

Keep the action plan pure.

PART 2 — CURRENT STATE → ACTION
==================================================

The backend must derive the action from:

- currentPhase
- currentNodeId
- activeCognitiveLevelId
- nodeTeachingStage
- activeTaskProvenance
- activeLessonExerciseId
- activeObjectiveTaskPayload
- learner intent
- evaluated/not-evaluated state where already available
- Decision Engine result where applicable

AI output must NOT determine which server action is current.

→ server action = DELIVER_THEORY

Phase 2 + active MICRO_CHECK + learner ANSWER
→ server action = EVALUATE_ACTIVE_TASK

Phase 2 + active source exercise + learner ANSWER
→ server action = EVALUATE_ACTIVE_TASK

evaluated answer + Decision Engine CONTINUE_COGNITIVE_LEVEL
→ server action = DELIVER_FEEDBACK / PREPARE_NEXT_LEARNING_ACTION
according to current architecture

ADVANCE_COGNITIVE_LEVEL
→ server action = ADVANCE_COGNITIVE_LEVEL

Do not invent transitions unsupported by current code.

==================================================
