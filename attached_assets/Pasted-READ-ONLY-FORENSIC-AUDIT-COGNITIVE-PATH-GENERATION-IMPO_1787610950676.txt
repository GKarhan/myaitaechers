==================================================

We are moving from Mapping Core to the next foundational layer:

→ Cognitive Path
→ Cognitive Levels
→ Teaching Content
→ AI Teacher

Mapping Core must remain untouched.

The long-term requirement is:

EVERY canonical MicroNode must be able to receive a complete,
auditable, pedagogically valid Cognitive Path automatically.

But the path must NOT blindly assign all Bloom levels.

The system must determine, from the MicroNode's actual learning
objective / knowledge / required learner performance:

1. the curriculum target cognitive level;
2. prerequisite/scaffolding cognitive levels needed to reach it;
3. a measurable performance objective for each required level;
4. a measurable success criterion;
5. suitable interaction/task types;
6. required independent evidence;
7. appropriate existing exercises/tasks for each level.

IMPORTANT PEDAGOGICAL PRINCIPLE:

Lower cognitive levels are progression/scaffolding toward the
MicroNode target. They are NOT separate MicroNodes.

Example:

MicroNode:
"Determine the zeros of a function from its graph"

A plausible path could be:

REMEMBER
→ recognize/recall what f(a)=0 means

UNDERSTAND
→ explain the relationship between zeros and intersections
  with the x-axis

APPLY — TARGET
→ independently determine zeros from a new graph

ANALYZE/EVALUATE/CREATE should NOT automatically be added unless
the MicroNode's curriculum target genuinely requires them.
