==================================================
CONTEXT — ALREADY APPROVED TEST 2.0 RULE
==================================================

The canonical educational rule is now:

1. Mapping defines the MicroNode and its Cognitive Path.

2. A normal quiz assesses ONLY the canonical target Cognitive Level
   of each selected MicroNode.

Examples:

Understand
→ quiz assesses Understand

Understand → Apply
→ quiz assesses Apply

Remember → Understand → Apply
→ quiz assesses Apply

Apply → Analyze
→ quiz assesses Analyze

3. The backend, NOT the AI provider, determines the target level.

4. AI Teacher is different:
   it may teach/check the mapped Cognitive Path level-by-level.

5. Normal quiz generation must NOT use
   EASY / MEDIUM / HARD / MIXED
   to decide what Bloom/Cognitive Level is being assessed.

6. Difficulty may potentially survive later only as a SECONDARY
   complexity modifier inside the SAME Cognitive Level.

Example:

Apply + simpler numerical conditions
Apply + more complex numerical conditions

Both are still Apply.

But this secondary difficulty concept is NOT approved for implementation yet.
