CORE PROBLEM TO AUDIT
==================================================

Persisting:

cognitiveLevelId = Apply

does NOT by itself prove that the generated question actually requires Apply-level cognition.

Example:

MicroNode:
"Զանգվածի միավորները և դրանց փոխակերպումը"

Target:
Apply

A valid Apply question might require the learner to actually perform a conversion in a new concrete case.

But a weak generated question such as:

"1 կգ-ը քանի՞ գրամ է"

may mostly test recall even if the database says:

cognitiveLevel = apply

Therefore we now need to determine whether the current system has a REAL semantic quality gate between:

MAPPED TARGET
        ↓
GENERATION CONTRACT
        ↓
GENERATED QUESTION
        ↓
QUESTION ACCEPTANCE/PERSISTENCE

We need evidence that the generated question actually measures the intended cognitive performance.
