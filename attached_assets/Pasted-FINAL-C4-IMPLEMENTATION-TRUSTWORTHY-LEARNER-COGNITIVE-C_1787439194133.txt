════════════════════════════════════════════════════
2. ONLY TRUST C3-QUALIFIED EVIDENCE FOR THE CEILING
════════════════════════════════════════════════════

Evidence may contribute to demonstrated Cognitive Level only when all required C3 conditions are satisfied.

At minimum require:

- qualification_status = qualified
- lesson_node_id matches the target MicroNode
- cognitive_level_id is non-null
- Cognitive Level belongs to the accepted/confirmed C2 path of that MicroNode
- answer/result is successful/correct
- evidence quality is permitted for cognitive confirmation
- assistance/help satisfies the independent-evidence policy
- task/source identity is valid

Explicitly EXCLUDE from demonstrated-ceiling confirmation:

- unqualified evidence
- legacy/null qualification evidence
- null cognitive_level_id evidence
- evidence from another MicroNode
- evidence for a Cognitive Level outside the accepted C2 path
- incorrect/failed evidence
- evidence with disqualifying assistance
- invalid task/source identity

Do NOT delete legacy evidence.
It simply must not establish the C4 demonstrated ceiling.

════════════════════════════════════════════════════

════════════════════════════════════════════════════
4. ENFORCE minimum_independent_evidence
════════════════════════════════════════════════════

For every Cognitive Level in the accepted C2 path:

read:

    minimum_independent_evidence

A level is sufficiently demonstrated only when it has enough qualifying independent evidence.

Do not allow one successful answer to establish a level when the configured minimum requires more.

Use stable task_reference/task identity when counting evidence.

At minimum, repeated persistence/replay of the exact same task reference must not artificially satisfy the required evidence count.

Prefer distinct qualifying task references for the required count.

Do not introduce semantic-diversity scoring in C4.

════════════════════════════════════════════════════
5. COMPUTE A CONTIGUOUS COGNITIVE CEILING
════════════════════════════════════════════════════

The accepted C2 Cognitive Path is ordered.

Example:

REMEMBER → UNDERSTAND → APPLY → ANALYZE

The learner ceiling is the highest CONTIGUOUS sufficiently demonstrated level from the beginning of the accepted path.

Example:

REMEMBER = sufficient
UNDERSTAND = sufficient
APPLY = insufficient
ANALYZE = sufficient

Result MUST be:

    UNDERSTAND

NOT ANALYZE.

Higher-level evidence must never skip an unresolved required lower level.

Algorithm conceptually:

for level in acceptedPath ordered ascending:
    if level satisfies its qualifying evidence requirement:
        ceiling = level
    else:
        stop

Persist the resulting highest contiguous level.

════════════════════════════════════════════════════
6. MAKE THE PERSISTED CEILING MONOTONIC
════════════════════════════════════════════════════

A legitimate already-demonstrated ceiling must NOT be erased merely because:

- the learner later fails a higher-level task;
- the learner receives remediation;
- a later lower-level task is attempted;
- a lower Cognitive Level is reconfirmed.

Example:

Persisted ceiling = APPLY

Later learner fails ANALYZE.

Persisted ceiling remains APPLY.

Later learner completes another UNDERSTAND task.

Persisted ceiling remains APPLY.

Do not implement cognitive decay/downgrade in C4.

Retention/revalidation policy belongs to later work.

If recomputation based on trustworthy evidence produces a lower result because of historical data anomalies, preserve the legitimate previously confirmed higher ceiling unless there is an explicit invalidation mechanism already present.

Do not invent an invalidation mechanism in C4.
