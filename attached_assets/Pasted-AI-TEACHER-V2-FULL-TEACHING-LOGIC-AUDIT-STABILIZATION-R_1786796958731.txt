============================================================
4. INTENDED AI TEACHER RESPONSIBILITY
============================================================

The AI Teacher should teach ONE current MicroNode at a time.

For the current MicroNode it should:

1. establish/activate relevant understanding
2. teach a bounded concept
3. ask ONE appropriate micro-check
4. wait for learner response
5. evaluate that response
6. provide targeted feedback
7. decide the appropriate next pedagogical action
8. continue teaching/checking OR move toward real exercise
9. use real source exercise when appropriate
10. collect sufficient valid evidence
11. only then allow backend-controlled node completion/progression

The AI must not casually decide:

"the student understands, let's move on"

without satisfying backend/evidence rules.

5. LOCKED TEACHING CYCLE
============================================================

Audit against this intended cycle:

TEACH
→ MICRO_CHECK
→ FEEDBACK
→ TRANSITION

Important:

MICRO_CHECK:
- exactly ONE assessable prompt
- preferably ≤25 words where pedagogically reasonable
- must wait for student response
- next pedagogical turn must process that response
- cannot silently become multiple questions
- cannot count as STRONG evidence

FEEDBACK:
- responds to the student's actual answer
- identifies correctness/error
- uses error taxonomy where relevant
- selects a pedagogical action
- should not accidentally skip required remediation

TRANSITION:
- decides whether to:
  - continue teaching
  - give another bounded check
  - remediate
  - move to real exercise
  - move toward node completion

Audit whether current code actually enforces these boundaries.
