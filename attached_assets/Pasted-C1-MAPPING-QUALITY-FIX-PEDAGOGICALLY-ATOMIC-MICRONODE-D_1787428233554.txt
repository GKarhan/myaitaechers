==================================================
2. CANONICAL MICRONODE DEFINITION
==================================================

A MicroNode is the smallest pedagogically meaningful unit that can be:

1. taught coherently;
2. checked independently;
3. supported directly by source;
4. associated with one clear learning objective;
5. assessed by one or more relevant tasks when such tasks exist.

Canonical rule:

ONE MicroNode
=
ONE clear independently teachable/assessable learning objective.

A MicroNode must NOT simply be:

- one paragraph;
- one heading;
- one source block;
- one sentence;
- one exercise;
- one Outcome;
- one arbitrary AI chunk.

==================================================
3. TWO FAILURE MODES MUST BOTH BE PREVENTED
==================================================

UNDER-SPLITTING:

Several independently assessable concepts/skills are merged into one
broad MicroNode.

Example pattern:

“definition + sequence properties + successor/predecessor + infinity”

inside one MicroNode even though the source/exercises independently
assess these skills.

OVER-SPLITTING:

One coherent learning objective is fragmented into multiple artificial
MicroNodes merely because:

- source spans multiple blocks;
- several examples exist;
- several exercises test the same knowledge;
- wording differs slightly.

The mapper must optimize for pedagogical atomicity, NOT maximum node
count.

==================================================
4. INDEPENDENT ASSESSABILITY TEST
==================================================

Before finalizing each candidate MicroNode boundary, ask:

Could a learner demonstrate mastery of A while still failing B?

If YES and A/B are both explicitly supported by the lesson source,
they are strong candidates for separate MicroNodes.

Examples of structurally different mastery:

- define/recognize X
versus
- apply a procedural relationship involving X

- explain a property
versus
- determine predecessor/successor

- recognize a category
versus
- locate/order values in a representation

But do not split when the distinction is merely wording or example
variation.

==================================================
5. EXERCISES ARE GRANULARITY EVIDENCE
==================================================

This is critical.

Textbook exercises/questions/tasks are not only content to preserve.

They are evidence about the intended knowledge granularity.

Before final MicroNode generation:

analyze each verified exercise and identify the primary knowledge/skill
required to solve it.

Then ask:

Does an existing candidate MicroNode have a learning objective that
actually teaches/tests that knowledge?

If YES:
align the exercise to that MicroNode.

If NO:
determine whether:

A. a pedagogically necessary MicroNode is missing;

or

B. the exercise is legitimately integrative/cumulative and should remain
additional.

Do NOT create a MicroNode merely to attach every exercise.

But do NOT leave an exercise “Additional” merely because the mapper
failed to create an obvious source-supported atomic knowledge unit.

11. “ADDITIONAL EXERCISE” DEFINITION
==================================================

An exercise may remain Additional only if:

- it integrates multiple MicroNodes;
- it is enrichment/generalization;
- it depends on prior/future lesson knowledge;
- or no single current MicroNode is its primary instructional owner.

“Mapper failed to create the necessary MicroNode” is NOT a legitimate
reason for Additional status.
