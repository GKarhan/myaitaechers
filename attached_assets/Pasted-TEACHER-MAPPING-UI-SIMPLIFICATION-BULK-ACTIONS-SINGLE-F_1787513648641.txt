1. TARGET TEACHER WORKFLOW
==================================================

The desired teacher workflow is:

1. Create lesson
2. Create / review / confirm Lesson Goal + Outcomes
3. Run Mapping
4. Generate Cognitive Paths for all eligible MicroNodes with ONE bulk action
5. Generate Teaching Content for all eligible MicroNodes with ONE bulk action
6. Teacher reviews the generated result
7. ONE final lesson approval
8. "Հանձնարարել սովորողին" becomes enabled only when canonical readiness passes

The teacher should NOT have to manually approve every small technical
sub-object individually unless something specifically requires review.

Backend validation stays strict.
