Implementation-ը ընդհանուր ուղղությամբ ճիշտ է, բայց verification-ը դեռ չեմ ընդունում։ Նախ ուղղիր/ստուգիր հետևյալները.

1. **Remove the 50-question cap.**

Իմ specification-ը հստակ է՝

`minimumQuestions = leafCount × 1`
`idealQuestions = leafCount × 3`

Չկա `min(50, ...)` սահմանափակում։

Օրինակ՝ 20 leaf → minimum 20, ideal 60։

2. **Prove that `quizLeafCount` is actually leaf-level Node/MicroNode count.**

Տուր `GET /api/lessons/:lessonId/nodes`-ի իրական response structure-ը և ցույց տուր, թե ինչպես ես տարբերակում parent Node-ը leaf Node/MicroNode-ից։

Իմ պահանջը leaf count-ն է, ոչ թե պարզապես fetched node array-ի length-ը։

Օրինակ՝

`5 Node × 2 MicroNode = 10 leaf`

Այսինքն՝ եթե API-ն վերադարձնում է parent Node + նրա MicroNode-երը, պետք է հաշվել իրական **leaf-level units**, ոչ թե parent Node-երի քանակը։

Նույն logic-ը պետք է ճիշտ աշխատի նաև multi-lesson scope-ի դեպքում։

3. **Complete real 3-question DB verification.**

Քո report-ում գրված `(0 rows)` նշանակում է, որ իրական 3-question case դեռ չի verified։

Ստեղծիր/օգտագործիր իրական 3-question quiz, կատարիր attempt և ցույց տուր DB query/result-ը տվյալ Node-ի համար՝

* 3 evidence events
* correct count
* mastery
* `confidenceScore`
* resulting Knowledge Tree level/status

Պետք է լինի իրական DB evidence, ոչ միայն code inspection։

**3/3, 2/3, 1/3 և 0/3 դեպքերը առանձին verify արա, եթե հնարավոր է։**

Եթե մեկ իրական quiz attempt-ով բոլոր 4 case-երը հնարավոր չէ ստանալ, օգտագործիր առանձին test attempts/test data և ցույց տուր յուրաքանչյուր tier-ի իրական արդյունքը։

Յուրաքանչյուր դեպքում ցույց տուր, որ արդյունքում ստացվում է հենց համապատասխան logic-ը.

* 3/3 → Գիտի
* 2/3 → Մասնակի գիտի — higher confidence
* 1/3 → Մասնակի գիտի — lower confidence
* 0/3 → Չգիտի

4. **Show the complete determination chain for the 4 blocks.**

Տուր `getMasteryLevel()`-ի և դրա caller-ի relevant code-ը և բացատրիր՝ ինչպես են

`mastered / weak / in_progress / not_started`

արժեքները վերածվում գոյություն ունեցող 4 Knowledge Tree blocks-ի։

Հստակ ցույց տուր՝

* որն է DB-level status-ը,
* որն է confidence/mastery value-ը,
* որտեղ է որոշվում final Knowledge Tree block-ը։

5. **Verify the 1/3 and 2/3 confidence tiers.**

Ցույց տուր, որ 2/3-ը և 1/3-ը երկուսն էլ գնում են **Մասնակի գիտի** block, բայց confidence-ը համապատասխանաբար higher/lower tier է։
