# PART B — MAKE THE LEARNING OBJECTIVE ATOMIC

Strengthen the learningObjective contract.

The existing prompt says one objective, but Job 20 proves that the model can still produce:

"Student can decompose a multi-digit number into classes AND read it using class names."

This is invalid.

Add an explicit hard rule:

### ABSOLUTE RULE — ONE ACTION PER LEARNING OBJECTIVE

"Every `learningObjective` MUST contain exactly ONE independently assessable action.

If an objective contains two independent actions, concepts, or outcomes connected by:

* and
* or
* then
* also
* as well as
* comma-separated independent actions
* equivalent conjunctions in the target language

the objective MUST be split into separate MicroNodes.

For example:

INVALID:
'Student can decompose a multi-digit number into classes and read it using class names.'

CORRECT:
MicroNode A:
'Student can decompose a multi-digit number into classes.'

MicroNode B:
'Student can read a multi-digit number using class names.'

Do NOT treat a prerequisite relationship as permission to combine two independently assessable skills.

A procedure may contain multiple STEPS, but those steps are allowed in one MicroNode only when they form one inseparable procedure with one final outcome.

Diagnostic test:
If two separate test questions can be written such that a student could answer one correctly while failing the other, they are separate learning objectives and MUST be separate MicroNodes."

Also add:

"Before finalizing each MicroNode, explicitly check:

* Does this LO have exactly one primary action?
* Does it describe exactly one concept/skill?
* Could another MicroNode be assessed independently from this one?
  If yes, split them."

# PART C — SPECIFIC CLARIFICATION FOR CONCEPT + APPLICATION

Do NOT over-split a procedure simply because its wording contains multiple verbs.

For example:

VALID ONE-MICRONODE:
"Student can decompose a multi-digit number into classes by grouping digits from right to left."

Here "grouping digits from right to left" is the method/step of ONE procedure.

INVALID:
"Student can decompose a multi-digit number and read it aloud."

These are two independently assessable outcomes.

The distinction is:

ONE PROCEDURE WITH STEPS → one MicroNode.

TWO INDEPENDENT OUTCOMES → two MicroNodes.
