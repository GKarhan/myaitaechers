1. APPROVED C7 TEACHING CONTRACT
==================================================

The canonical teaching cycle is:

TEACH
→ MICRO_CHECK
→ FEEDBACK
→ TRANSITION

The AI Teacher must not skip or blur these stages.

TEACH:
- teach only CURRENT_NODE / CURRENT Cognitive Level
- explain the current knowledge target
- use source-backed content
- do not ask the evidence question prematurely

MICRO_CHECK:
- exactly one short check
- preferably ≤25 words where practical
- evaluates the just-taught point
- next learner turn must go to FEEDBACK

FEEDBACK:
- explicitly evaluate learner response
- identify error family when relevant
- give short concrete feedback
- decide remediation / next action deterministically

TRANSITION:
- either:
  - another teach/remediation step,
  - appropriate real exercise,
  - next cognitive level,
  - node completion handoff to C6,
  - or bounded revisit state.

Audit whether this is actually enforced today.
