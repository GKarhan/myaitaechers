════════════════════════════════════════════════════════════
1. CORE INVARIANT — INDEPENDENT ASSESSABILITY
════════════════════════════════════════════════════════════

Add this fundamental Mapping Contract invariant:

Two related knowledge candidates must remain separate MicroNodes when:

A learner can reasonably demonstrate mastery of one without demonstrating
mastery of the other.

Equivalent question:

"DO THESE REQUIRE SEPARATE LEARNER MASTERY STATES?"

If YES:
they must remain separate canonical MicroNodes.

If NO:
they may consolidate into one MicroNode.

This invariant must constrain:

- candidate promotion
- semantic consolidation
- canonical grouping
- atomicity review
- final map completeness validation

════════════════════════════════════════════════════════════
2. DIRECTIONAL / TRANSFORMATION DISTINCTION
════════════════════════════════════════════════════════════

Do not assume reverse operations are the same knowledge.

Examples:

A → B

and

B → A

may be strongly related but independently assessable.

Examples:

graph → infer intervals
intervals → construct graph

word → identify grammatical category
properties → identify the word/category

observation → infer cause
conditions → predict observation

formula → calculate value
value/constraint → construct formula

These should remain separate when mastery can diverge.

Do NOT create a generic hardcoded “reverse direction always separate” rule.

Instead use the independent-assessability invariant.

6. EXERCISE COVERAGE AS A MISSING-KNOWLEDGE SIGNAL
════════════════════════════════════════════════════════════

Exercises are NOT automatically knowledge nodes.

But exercises provide strong evidence about what the textbook expects the
learner to be able to do.

After final MicroNodes exist, inspect exercises/tasks.

For each real instructional exercise ask:

"Is there at least one canonical MicroNode whose learning objective provides
the knowledge/skill required by this task?"

If several related exercises require the same independently assessable ability
and no MicroNode covers it:

create a COMPLETENESS REVIEW FINDING.

Do NOT automatically manufacture a MicroNode from an exercise.

But do not silently accept:

exercise exists
+
no supporting knowledge unit

either.

8. MISSING-KNOWLEDGE REPAIR
════════════════════════════════════════════════════════════

When completeness audit identifies a likely missing independently assessable
knowledge unit:

FIRST determine whether a prior candidate was incorrectly suppressed.

Preferred recovery order:

1. restore/reclassify an existing source-grounded candidate
2. split an incorrectly consolidated canonical group
3. if no adequate candidate exists, derive ONE source-grounded repair candidate
   from already verified instructional evidence
4. if semantic certainty is insufficient → REVIEW_REQUIRED

Do NOT create a new provider call per gap.

Reuse existing bounded semantic review if semantic judgment is required.

Do not fabricate source content.

════════════════════════════════════════════════════════════
9. CONSOLIDATION MUST CHECK INDEPENDENT ASSESSABILITY
════════════════════════════════════════════════════════════

Before SAME_KNOWLEDGE consolidation is applied, require:

same underlying learner mastery state

AND

no independently assessable distinction.

If two candidates have:

- different input → output transformations
- different required learner performances
- independently distinguishable evidence
- different success criteria

then they should normally remain DISTINCT_KNOWLEDGE.

Even if:

- topic vocabulary is identical
- source paragraphs are adjacent
- one concept is the inverse of another
- both are described under the same textbook heading.

════════════════════════════════════════════════════════════
10. COGNITIVE DEPTH STILL MUST NOT CREATE NEW MICRONODES
════════════════════════════════════════════════════════════

Do NOT confuse this fix with Bloom-level splitting.

These should still normally remain ONE MicroNode:

state X
explain X
apply X

when they are cognitive depths of the SAME underlying knowledge.

But these may remain separate:

interpret representation X
construct representation X

if independently assessable.

The distinction is learner-state identity, not verb wording.

════════════════════════════════════════════════════════════
11. SUCCESS-CRITERION TEST
════════════════════════════════════════════════════════════

Use this conceptual test during semantic identity decisions:

If Candidate A and Candidate B were one MicroNode, could we write ONE clear
success criterion that validly proves mastery of BOTH?

If NO:
they are probably separate learner states.

Example:

"Correctly determines sign intervals from a graph"

does NOT prove:

"Can construct a graph from sign intervals."

Therefore they should not be merged.

This is a semantic rule, not a string heuristic.

════════════════════════════════════════════════════════════
12. EVIDENCE-SET TEST
════════════════════════════════════════════════════════════

Another signal:

If the same evidence/task can independently verify both candidate objectives,
they may be the same learner state.

If Candidate A requires one type of evidence and Candidate B requires another
distinct performance, that is evidence for separate MicroNodes.

Do not require identical exercise formats.

Use conceptual evidence requirements.
