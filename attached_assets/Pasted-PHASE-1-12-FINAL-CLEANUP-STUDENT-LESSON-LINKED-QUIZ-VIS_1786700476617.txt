PART 1 — REQUIRED STUDENT UX
════════════════════════════════════════════

For every quiz linked to an assigned lesson:

STATE A — NOT RELEASED

Teacher has not released the quiz to this student/current assignment.

Under the lesson show:

    Դեռ հասանելի չէ

There must be NO start button.

────────────────────────────────────────────

STATE B — RELEASED + NOT YET COMPLETED

Teacher has released the quiz and the current release has not yet been
completed by the student.

Under the lesson show:

    ▶ Սկսել թեստը

The button must open the existing quiz-taking route.

Do not change quiz-taking behavior.

────────────────────────────────────────────

STATE C — CURRENT RELEASE COMPLETED

The student has completed/submitted the quiz for the current release.

REMOVE THAT QUIZ FROM THE LINKED-QUIZZES LIST UNDER THE LESSON.

Do NOT show:

    Սկսել թեստը

Do NOT show another duplicate:

    Տեսնել արդյունքը

under the lesson.

The completed quiz/result already belongs in:

    Իմ թեստերը

where the existing UI should continue showing something equivalent to:

    Ավարտված · 3/10 (30%)
    Տեսնել արդյունքը

Therefore:

LESSON = what the student still needs/can do.
ԻՄ ԹԵՍՏԵՐԸ = completed quiz history/results.

════════════════════════════════════════════
PART 2 — RE-RELEASE OF THE SAME QUIZ
════════════════════════════════════════════

This is CRITICAL.

Completing Quiz X once must NOT permanently make Quiz X disappear forever.

Required lifecycle:

Teacher releases Quiz X
        ↓
Student sees "Սկսել թեստը"
        ↓
Student completes it
        ↓
Quiz X disappears from the lesson's actionable quiz list
        ↓
Result remains in "Իմ թեստերը"
        ↓
Teacher explicitly releases/assigns Quiz X again
        ↓
Quiz X MUST appear under the lesson again
        ↓
Student again sees "Սկսել թեստը"
        ↓
A new attempt can be completed.

Historical attempts/results must remain intact.

Do NOT delete or overwrite Attempt 1 when Attempt 2 is created.

Do NOT duplicate the Quiz record merely to re-release it.

Same Quiz ID may have multiple historical attempts/releases if the
existing architecture supports that.

Audit the current assignment/attempt model and implement this using the
existing authoritative model wherever possible.

If the current schema cannot distinguish:

    "this quiz was completed sometime in the past"

from

    "this current teacher release has been completed"

STOP before schema changes and report the exact limitation and the
smallest schema/model change required.

Do not silently implement a workaround based only on latest attempt.
