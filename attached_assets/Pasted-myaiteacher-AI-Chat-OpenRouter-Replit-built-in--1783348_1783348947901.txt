myaiteacher-ում AI Chat-ը միացրու OpenRouter-ի միջոցով (Replit built-in):

─────────────────────────────────────────────
1. 🤖 OPENROUTER INTEGRATION
─────────────────────────────────────────────

- Օգտագործել Replit-ի ներկառուցված OpenRouter API-ն
- API Endpoint: https://openrouter.ai/api/v1/chat/completions
- Մոդել: deepseek/deepseek-r1:free (կամ deepseek/deepseek-chat:free)
- API Key: Replit-ն ավտոմատ կտրամադրի (շրջակա միջավայրի փոփոխական)

─────────────────────────────────────────────
2. BACKEND (Node.js + Express)
─────────────────────────────────────────────

- Ստեղծել aiService.js (կամ aiService.py)
- OpenRouter API-ի հարցումներ
- System Prompt-ը ներառված է
- Յուրաքանչյուր հարցում պահվում է SQLite-ում

─────────────────────────────────────────────
3. API ENDPOINT
─────────────────────────────────────────────

POST /api/chat
- Input: { message, student_id, lesson_id }
- Output: { response, profile }

─────────────────────────────────────────────
4. SYSTEM PROMPT (AI-ի հրահանգ)
─────────────────────────────────────────────

Դու myaiteacher-ի AI ուսուցիչն ես:
- Պատասխանում ես միայն հայերեն
- Օգտագործում ես Սոկրատյան մեթոդը (հարցերով առաջնորդում)
- Չես տալիս պատրաստի պատասխաններ
- Աշխատում ես միայն ներբեռնված դասագրքով
- Օգտագործում ես 8-փուլյա ալգորիթմը

─────────────────────────────────────────────
5. FRONTEND
─────────────────────────────────────────────

- Chat ինտերֆեյս (chat.html կամ Chat.jsx)
- Messages, input, send button
- AI-ի պատասխանները ցուցադրվում են
- JSON պրոֆիլը ցուցադրվում է (ըստ ցանկության)

─────────────────────────────────────────────
6. .ENV (ԸՆՏՐՈՎԱԿԱՆ)
─────────────────────────────────────────────

- Replit-ն ավտոմատ կտրամադրի OPENROUTER_API_KEY
- Կարող եք ավելացնել սեփականը (եթե ունեք)

─────────────────────────────────────────────
7. ՏՐԱՄԱԴՐԻՐ ԱՄԲՈՂՋԱԿԱՆ ԿՈԴԸ
─────────────────────────────────────────────

- Backend (aiService.js, chat routes)
- Frontend (chat.html)
- System Prompt-ը ներառված է
- SQLite-ում պահվում են զրույցները
