PART 1 — FIX THE UI TERMINOLOGY
==================================================

There is currently a semantic naming problem.

The UI shows wording equivalent to:

"Սովորելու արդյունավետություն"

next to coveragePercent.

THIS IS WRONG.

coveragePercent does NOT mean learning efficiency.

It means only:

How much of the available curriculum / MicroNodes
the learner has already studied or generated evidence for.

Example from the current real Physics data:

totalUnits = 3
studiedCount = 3
masteredCount = 0
partialCount = 1
doesNotKnowCount = 2
notStudiedCount = 0
coveragePercent = 100

This means:

Ուսումնասիրված՝ 3 / 3 · 100%

It DOES NOT mean:

Սովորելու արդյունավետություն՝ 100%

Replace all learner-facing labels where coveragePercent is described
as learning efficiency/mastery with clear Armenian coverage terminology.

Preferred wording:

"Ուսումնասիրված"

Example:

Ուսումնասիրված՝ 3 / 3 · 100%

For Subject cards, Lesson rows, Topic rows and subject header,
use consistent terminology.

IMPORTANT:

Reserve the concept "Սովորելու արդյունավետություն"
for the future Efficiency Engine:
