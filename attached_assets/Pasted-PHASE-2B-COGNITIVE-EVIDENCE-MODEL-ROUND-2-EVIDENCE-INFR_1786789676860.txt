============================================================

Create a durable help_events table if no equivalent currently exists.

help_level

boolean NOT NULL DEFAULT false

timestamp with timezone NOT NULL default now()

Help levels:

1 = light
2 = moderate
3 = guided
4 = reveal

Semantics:

LEVEL 1 — LIGHT
Directional hint.
Must not provide solution steps or final answer.

LEVEL 2 — MODERATE
More specific conceptual/procedural guidance.
Still should not reveal the final answer.

LEVEL 3 — GUIDED
Step-by-step support.
Learner is still expected to produce/choose the final response.

LEVEL 4 — REVEAL
Explicit explanation/final-answer reveal.
This must be treated separately from normal hints.

Store the ACTUAL help event.

Do not merely increment a counter.

The final evidence row later stores the summary:

help_count = number of help events before answer

assistance_level =
none
light
moderate
guided
revealed

hint_used =
false only when no help was used
true when level >= 1 occurred before final answer.

PART 6 — PROGRESSIVE HELP BACKEND
============================================================

Implement the backend foundation for the AI Teacher help interaction.

Preferred architecture:
a dedicated help request endpoint or equivalent isolated action.

The action MUST receive/derive the authenticated learner and current
active task from server-side session state.

Do NOT trust client-supplied:
userId
lessonNodeId
cognitiveLevel
exerciseId

when those values can be derived from the authenticated session.

On help request:

1. Validate the lesson session belongs to the authenticated learner.

2. Validate there is an active unanswered task.

3. Determine next help level:
   0 → 1
   1 → 2
   2 → 3

4. Level 4 REVEAL must NOT happen automatically.
   It requires a distinct explicit action.

5. Generate or retrieve help appropriate to the SAME task.

6. Insert help_events row.

7. Update active-task help summary if such session state is persisted.

8. Return:
   - task identity
   - help level
   - hint text
   - whether reveal occurred

9. DO NOT:
   - advance node_teaching_stage
   - increment answer evidence
   - mark task correct
   - complete MicroNode
   - generate a replacement question

The AI prompt for help MUST receive enough context to know the exact
current task and prior hints.

It must explicitly prohibit premature answer reveal at levels 1–3.
