# 3. Կարևոր — չսահմանափակվել միայն այս բառերի որոնմամբ

Կատարել repository-wide որոնում այնպիսի mixed-script strings-ի համար, որտեղ հայերեն բառի մեջ հայտնվում են՝

* Latin characters
* Cyrillic characters
* այլ Unicode այբուբենների տառեր

Օրինակ՝

`А`, `В`, `С`, `Е`, `К`, `о`, `р`, `т`, `с`, `х`, `ш`, `н`, `а`

և Latin տառեր՝

`A-Z`, `a-z`

Հայերեն display text-ի ներսում։

Բայց **չփոխել իրական տեխնիկական identifiers-ը**, օրինակ՝

* variable names
* function names
* database columns
* API fields
* TypeScript types
* route names
* English technical terminology

Փոփոխել միայն այն text strings-ը, որոնք ցուցադրվում են օգտատիրոջը կամ օգտագործվում են որպես user-facing labels.

---

# 4. Frontend + Backend ստուգում

Ստուգել ոչ միայն `quiz-result.tsx`-ը, այլ ամբողջ chain-ը.

`quiz generation`
→ `API response`
→ `buildStudentResultAnalysis`
→ `quiz-result.tsx`
→ displayed labels

Եթե mixed-script տեքստը գալիս է backend-ից, ուղղել backend source string-ը։

Եթե գալիս է frontend-ից, ուղղել frontend string-ը։

Չպետք է պարզապես UI-ում mask/replace անել ամբողջ response-ի վրա։

# 5. Feedback text-ի կարևոր կանոն

PART 3.5-ում արդեն ներդրված է՝

և՝

`whyCorrect = option_explanations[correctOptionIndex]`

`whyWrong = option_explanations[selectedOptionIndex]`

Այս logic-ը **ՉՓՈԽԵԼ**։

Պետք է միայն համոզվել, որ AI-ի գեներացրած explanation text-ը նույնպես հայերեն է և չի պարունակում mixed-script բառեր։

`Ճիշտ է, քանի որ յուրաքանչյուր երեք հաջորդական կարգ կազմում է մեկ դաս։`

# 9. Acceptance Criteria

Fix-ը համարել ավարտված միայն եթե՝

1. `Արդյունքներ` → ամբողջությամբ հայերեն է։
2. `ճիշտ` → ամբողջությամբ հայերեն Unicode է։
3. `պատասխան` → ամբողջությամբ հայերեն Unicode է։
4. `Ինչու է ճիշտ` → ամբողջությամբ հայերեն է։
5. `Ինչու է սխալ` → ամբողջությամբ հայերեն է։
6. `Խորացված ուսուցում` → ամբողջությամբ հայերեն է։
7. Recommendation labels-ը ամբողջությամբ հայերեն են։
8. Quiz question text-ը չի պարունակում mixed-script հայերեն։
9. Option text-ը չի պարունակում mixed-script հայերեն։
10. `optionExplanations[]`-ի generated text-ը չի պարունակում mixed-script հայերեն։
11. Technical identifiers-ը չեն փոխվել։
12. Scoring/mastery/evidence logic-ը չի փոխվել։
13. `whyCorrect / whyWrong` logic-ը չի փոխվել։
14. Existing quiz-ը շարունակում է աշխատել։
15. New quiz generation-ը նույնպես վերադարձնում է մաքուր հայերեն։
