myaiteacher-ում Student Dashboard-ում կատարել հետևյալ փոփոխությունները.

─────────────────────────────────────────────
1. 🏷️ ՈՂՋՈՒՅՆ
─────────────────────────────────────────────

- "Բարի գալուստ, Ադմինիստրատոր 👋" → փոխարինել "Բարի գալուստ, [Աշակերտի Անուն Ազգանուն]"
- Օրինակ՝ "Բարի գալուստ, Արամ Կարապետյան"

─────────────────────────────────────────────
2. 📊 ՎԻՃԱԿԱԳՐՈՒԹՅՈՒՆ
─────────────────────────────────────────────

- Հեռացնել վիճակագրության բլոկը (Ավարտված դասեր, Միջին գնահատական, Չներկայացված, Առաջընթաց)
- Քանի որ դեռ տվյալներ չկան, դրա կարիքը չկա

─────────────────────────────────────────────
3. 📅 ԴԱՍԱՑՈՒՑԱԿ
─────────────────────────────────────────────

- Ցույց է տալիս աշակերտի դասացուցակը
- Մեր պարագայում՝ Հանրահաշիվ, 7-րդ դասարան
- [Սովորել] կոճակ → տանում է դասի էջ

─────────────────────────────────────────────
4. 📚 ԱՌԱՐԿԱՆԵՐ
─────────────────────────────────────────────

- Ցույց է տալիս աշակերտի առարկաները
- Մեր պարագայում՝ միայն Հանրահաշիվ
- Ապագայում ավելացվող առարկաները պետք է դինամիկ երևան

─────────────────────────────────────────────
5. 🗺️ ԳԻՏԵԼԻՔԻ ՔԱՐՏԵԶ
─────────────────────────────────────────────

- Ցույց է տալիս առարկաների թեմաները
- Գունավորում.
  🟢 ≥80% → "Յուրացված"
  🟡 50-79% → "Թույլ"
  🔴 <50% → "Չսկսված"
- Ցույց է տալիս միայն ավելացված առարկաները

─────────────────────────────────────────────
6. 👨‍🏫 ՈՒՍՈՒՑԻՉՆԵՐ
─────────────────────────────────────────────

- Ցույց է տալիս աշակերտի ուսուցիչներին
- Կարող է մնալ

─────────────────────────────────────────────
7. 📋 ԱՆՁՆԱԿԱՆ ՏՎՅԱԼՆԵՐ
─────────────────────────────────────────────

- "📋 Անձnakan" → փոխարինել "📋 Անձնական տվյալներ"
- Կարող է մնալ

─────────────────────────────────────────────
8. 🏠 ՏՆԱՅԻՆ
─────────────────────────────────────────────

- Հեռացնել ժամանակավորապես
- Քանի որ դեռ տնայիններ չկան

─────────────────────────────────────────────
9. 📖 ԴԱՍԻ ԷՋ
─────────────────────────────────────────────

- Դասացուցակից [Սովորել] կոճակը տանում է դասի էջ
- Դասի էջը պետք է ցույց տա.
  - Դասի բովանդակությունը
  - Knowledge Tree (6 մակարդակ)
  - AI Chat (OpenRouter)
  - 8 փուլ (Review → Core → Secondary → Application → Creative → Project → Summary → Homework)
- Դասերը բերվում են ուսուցչի կողմից ստեղծված ցանկից

─────────────────────────────────────────────
10. 🚀 ԸՆԴՀԱՆՈՒՐ
─────────────────────────────────────────────

- Բոլոր տերմինները հայերեն են
- "Բարի գալուստ, [Աշակերտի Անուն Ազգանուն]"
- "Դասացուցակ"
- "Առարկաներ"
- "Գիտելիքի քարտեզ"
- "Ուսուցիչներ"
- "Անձնական տվյալներ"
- "Տնային" (ժամանակավորապես հեռացված)

─────────────────────────────────────────────
11. 📌 ՊԱՀԱՆՋՆԵՐ
─────────────────────────────────────────────

- Աշակերտը մուտք է գործում student1 / student123
- "Բարի գալուստ, Արամ Կարապետյան"
- Դասացուցակում՝ Հանրահաշիվ (7-րդ դասարան)

- Առարկաները դինամիկ են (ըստ ավելացվածի)
