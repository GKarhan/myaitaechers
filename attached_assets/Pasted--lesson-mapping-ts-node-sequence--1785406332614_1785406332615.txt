ԽՆԴԻՐ. lesson-mapping.ts-ը ընդլայնել, որպեսզի node-երի հերթականությունը
(sequence) հաշվարկվի ԿՈԴՈՎ՝ ելնելով node-երի իրական կախվածությունից, ոչ թե
model-ի JSON array-ի պատահական կարգից։ Սա P1 սպեցի STEP 5 (Essential Question),
STEP 11 (Prerequisite Map) և STEP 12 (Dependency Graph) քայլերի իրական
իրականացումն է։

Կարևոր. knowledge_nodes/knowledge_edges աղյուսակները ՄԻ խառնիր սրա հետ. դրանք
յուրաքանչյուր ՈՒՍԱՆՈՂԻ անհատական mastery-tracking գրաֆն են (userId-ով), իսկ
այստեղ խոսքը դասի ՔԱՐՏԵԶԱԳՐՄԱՆ ժամանակի (authoring-time), մեկ դասի node-երի
միջև եղած կախվածության գրաֆի մասին է։ Սրանք տարբեր հասկացություններ են,
պահիր առանձին։

    id: serial("id").primaryKey(),
    lessonId: integer("lesson_id").notNull().references(() => lessonsTable.id, { onDelete: "cascade" }),
    fromNodeId: integer("from_node_id").notNull().references(() => lessonNodesTable.id, { onDelete: "cascade" }), // prerequisite-ը

    requiredLevel: text("required_level").notNull().default("SUPPORTING"),   // CRITICAL | SUPPORTING
    reason: text("reason"),
    createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
  });

"nodeDependencies — սահմանիր ՄԻԱՅՆ այս դասի node-երի միջև եղած իրական
կախվածությունը (ոչ արտաքին/նախորդ դասերի գիտելիք — դա assumedPriorKnowledge-ի

- REQUIRED. toNodeTitle-ը լիովին անհասկանալի կլինի առանց fromNodeTitle-ի

- CONCEPTUAL. հասկացությունները կապված են, բայց ոչ խիստ հաջորդական
