ԽՆԴԻՐ. lesson-mapping.ts-ը (արդեն ուղղված) այժմ վերադարձնում է 3 նոր դաշտ.
knowledgeBoundaries (lesson-մակարդակ), verbatimTheoryAnchor և nonExamples
(node-մակարդակ)։ Այս դաշտերը դեռ ոչ մի տեղ չեն պահվում DB-ում և չեն
օգտագործվում chat.ts-ի կողմից։ Պետք է. (ա) ավելացնել DB column-ներ,
(բ) գտնել /map route-ը (որտեղ mapLessonWithAI()-ի արդյունքն insert է
արվում lessonsTable/lessonNodesTable-ում) և պահել այս 3 դաշտերը,
(գ) chat.ts-ում իրապես օգտագործել դրանք։

Գտիր routes-ը, որտեղ mapLessonWithAI()-ի կանչից հետո insert է կատարվում

3.3. lesson-ի select-ից (որտեղ lesson-ը fetch-վում է lessonId-ով), ավելացրու
lesson.knowledgeBoundaries-ի ընթերցում. այն արդեն jsonb է, կարիք չկա cast անել,
բայց ավելացրու type-assertion, ինչպես coreProblem-ի/coreIdea-ի համար է արված.
  const knowledgeBoundaries = (lesson as { knowledgeBoundaries?: string[] }).knowledgeBoundaries ?? [];

3.4. Ավելացրու 2 նոր block, cfeBlock/examplesBlock-ի կողքին, ուղիղ այս
ձևակերպումով (ԲԱՌ ԱՌ ԲԱՌ, ոչ ձեռքով-վերաշարադրված).

  const verbatimAnchorBlock = currentNodeRecord?.verbatimTheoryAnchor
    ? `\nVERBATIM_THEORY_ANCHOR (եթե ոչ դատարկ, հիմնվիր հենց սրա վրա, մեջբերիր մոտավորապես բառ առ բառ, հատկապես կանոններ/սահմանումներ ներկայացնելիս).\n${currentNodeRecord.verbatimTheoryAnchor}`
    : "";

  const nonExamplesArr = toStrArr(currentNodeRecord?.nonExamples);
  const nonExamplesBlock = nonExamplesArr.length > 0
    ? `\nNON_EXAMPLES (օգտագործիր սրանք որպես հակադրություն, MICRO_CHECK-ի սխալ տարբերակների աղբյուր).\n${nonExamplesArr.map((e, i) => `${i + 1}. ${e}`).join("\n")}`
    : "";

  const knowledgeBoundariesBlock = knowledgeBoundaries.length > 0
    ? `\nKNOWLEDGE_BOUNDARIES (այս դասը ԴԻՏԱՎՈՐՅԱԼ ՉԻ ընդգրկում սրանք. մի խորանա/մի բացատրիր, եթե աշակերտը հարցնի, ասա որ դա հաջորդ դասերում կլինի).\n${knowledgeBoundaries.map((b: string, i: number) => `${i + 1}. ${b}`).join("\n")}`
    : "";
