# ՄԵՐ ՎԵՐՋՆԱԿԱՆ ՆՊԱՏԱԿԸ

Test-ից հետո սովորողը պետք է ստանա.

### 1. Question-level feedback

Յուրաքանչյուր հարցի համար՝

* հարցը
* սովորողի ընտրած պատասխանը
* ճիշտ պատասխանը
* ճիշտ/սխալ արդյունքը
* եթե ճիշտ է՝ կարճ բացատրություն՝ **ինչու է ճիշտ պատասխանը ճիշտ**
* եթե սխալ է՝

  * ինչու է սովորողի ընտրած պատասխանը սխալ
  * ինչու է ճիշտ պատասխանը ճիշտ

Այս feedback-ը պետք է լինի ուսուցողական, ոչ միայն «Correct/Incorrect»։

---

### 2. Individual student analysis

Test-ից հետո համակարգը պետք է կարողանա հասկանալ՝ տվյալ սովորողի մոտ.

* ինչն է լավ յուրացված
* ինչն է մասնակի յուրացված
* ինչը չգիտի
* ինչը դեռ չի ուսումնասիրել
* կոնկրետ որ Node/MicroNode-ներում կա բաց

Knowledge Tree-ի 4 վիճակներն են՝

1. **Գիտի**
2. **Մասնակի գիտի**
3. **Չգիտի**
4. **Դեռ չի ուսումնասիրել**

Մասնակի գիտի վիճակը հետագայում պետք է պահպանի granular տարբերությունը, օրինակ՝

* 1/3 → ավելի մեծ բաց
* 2/3 → ավելի փոքր բաց

Նոր DB column ինքնուրույն չավելացնել։

---

### 3. Class-wide analysis

Ամբողջ դասարանի Test պատասխաններից համակարգը հետագայում պետք է կարողանա հայտնաբերել ընդհանուր սխալներ։

Եթե նույն գիտելիքի/հարցի/Node-ի հետ կապված նույն սխալը կատարել է դասարանի **50% կամ ավելի** մասը, դա պետք է համարվի class-wide issue։

Ուսուցչի համար հետագայում պետք է հնարավոր լինի ցույց տալ.

* որ Node/MicroNode-ում կա ընդհանուր դժվարություն
* քանի սովորող է սխալվել
* տոկոսը
* ինչ սխալ pattern է կրկնվում

Բայց այս փուլում ոչինչ մի implement արա։

---

### 4. Individual recommendations

Test-ից հետո տվյալ սովորողի համար հետագայում պետք է հնարավոր լինի ստեղծել recommendation՝

**Գիտի**
→ կրկնել

**Մասնակի գիտի**
→ նպատակային սովորել՝ ըստ բացի աստիճանի

**Չգիտի**
→ լիարժեք սովորել

**Դեռ չի ուսումնասիրել**
→ սկզբնական սովորել

Կարևոր է՝ սա ապագայում պետք է դառնա **Personalization Engine-ի input**, ոչ թե պարզապես static recommendation text։
