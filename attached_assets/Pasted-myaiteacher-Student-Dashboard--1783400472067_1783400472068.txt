myaiteacher-ում ավելացրու Student Dashboard-ը բոլոր ֆունկցիաներով:

─────────────────────────────────────────────
1. 👨‍🎓 STUDENT DASHBOARD
─────────────────────────────────────────────

- Մուտք student-ի համար (student1 / student123)
- Student-ը տեսնում է.
  - Իր դասացուցակը (օր, ժամ, առարկա, ուսուցիչ)
  - Իր առարկաները (ցուցակ, առաջընթաց %)
  - Իր ուսուցիչներին
  - Իր առաջընթացը (ընդհանուր %)
  - Իր գիտելիքի քարտեզը (ընդհանուր)
  - Իր տնային աշխատանքները

─────────────────────────────────────────────
2. 📅 ԴԱՍԱՑՈՒՑԱԿ
─────────────────────────────────────────────

- Ցույց է տալիս student-ի այսօրվա դասերը
- Օր, Ժամ, Առարկա, Ուսուցիչ
- [Սկսել] կոճակ → տանում է դասի էջ (AI-ն սկսում է)

─────────────────────────────────────────────
3. 📚 ԱՌԱՐԿԱՆԵՐ
─────────────────────────────────────────────

- Ցույց է տալիս student-ի բոլոր առարկաները
- Առարկայի անուն, առաջընթաց (%), ուսուցիչ
- [Դիտել] կոճակ → տանում է առարկայի էջ

─────────────────────────────────────────────
4. 📄 ԱՌԱՐԿԱՅԻ ԷՋ (Subject Page)
─────────────────────────────────────────────

- Առարկայի անուն, ուսուցիչ, դասարան
- Ընդհանուր առաջընթաց (%)
- Դասերի ցանկ (համար, վերնագիր, կարգավիճակ, գնահատական)
- [Սկսել] / [Շարունակել] կոճակ յուրաքանչյուր դասի համար
- Գիտելիքի քարտեզ (🟢🟡🔴)
  - Թեմաներ, առաջընթաց (%)
  - [Սովորել] / [Կրկնել] կոճակներ
- Տնային աշխատանքներ (ըստ դասերի)

─────────────────────────────────────────────
5. 🗺️ ԳԻՏԵԼԻՔԻ ՔԱՐՏԵԶ (ԸՆԴՀԱՆՈՒՐ)
─────────────────────────────────────────────

- Բոլոր առարկաների ամփոփ ցուցակը
- Գունավորում.
  🟢 ≥80% → "Յուրացված"
  🟡 50-79% → "Թույլ"
  🔴 <50% → "Չսկսված"
- [Դիտել] → տանում է առարկայի էջ

─────────────────────────────────────────────
6. 📖 ԴԱՍԻ ԷՋ (Lesson Page — AI Tutor)
─────────────────────────────────────────────

- Դասի վերնագիր, առարկա, ուսուցիչ
- Բովանդակություն (տեքստ, նկարներ)
- Knowledge Tree (6 մակարդակ — Bloom)
  🟢 Level 1 (Հիշել)
  🟡 Level 2 (Հասկանալ)
  🔴 Level 3 (Կիրառել)
  ⚪ Level 4 (Վերլուծել)
  ⚪ Level 5 (Գնահատել)
  ⚪ Level 6 (Ստեղծել)
- AI Chat (OpenRouter / DeepSeek)
  - Messages, input, send
  - AI-ն պատասխանում է հայերեն (Սոկրատյան մեթոդ)
- 8 փուլ (Review → Core → Secondary → Application → Creative → Project → Summary → Homework)
- Ընթացիկ առաջընթաց (progress bar)

─────────────────────────────────────────────
7. 🏠 ՏՆԱՅԻՆ ԱՇԽԱՏԱՆՔ
─────────────────────────────────────────────

- Ցույց է տալիս բոլոր տնայինները (ըստ դասերի)
- Կարգավիճակ.
  🟡 Սպասում է (Pending)
  🟢 Գնահատված (Graded) — ցույց է տալիս գնահատականը
  🔴 Չի ներկայացվել (Not Submitted)
- [Ներկայացնել] → բացում է ձև (տեքստային պատասխան)
- [Տեսնել] → ցույց է տալիս արձագանքը (ուսուցչի)

─────────────────────────────────────────────
8. 📊 ԱՌԱՋԸՆԹԱՑ (ՎԻՃԱԿԱԳՐՈՒԹՅՈՒՆ)
─────────────────────────────────────────────

- Ընդհանուր առաջընթաց (%)
- Ավարտված դասեր / Ընդհանուր դասեր
- Միջին գնահատական
- Յուրացման մակարդակ (%)
- Ակտիվ դասեր (ընթացքի մեջ)
- Վերջին ակտիվությունը (վերջին 3 դասերը)

─────────────────────────────────────────────
9. API
─────────────────────────────────────────────

- GET /api/student/dashboard — student-ի բոլոր տվյալները
- GET /api/student/subjects — student-ի առարկաները
- GET /api/student/subject/:id — առարկայի տվյալները
- GET /api/student/lessons/:subject_id — դասերի ցանկը
- GET /api/student/lesson/:id — դասի բովանդակությունը
- GET /api/student/knowledge-map — գիտելիքի քարտեզը
- GET /api/student/knowledge-map/:subject_id — առարկայի քարտեզը
- GET /api/student/homework — բոլոր տնայինները
- POST /api/student/homework/:id/submit — ներկայացնել տնային
- POST /api/student/chat — AI Chat (OpenRouter)
