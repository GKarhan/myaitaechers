myaiteacher-ում ավելացրու Admin Dashboard-ը բոլոր ֆունկցիաներով:

─────────────────────────────────────────────
1. 👑 ADMIN DASHBOARD
─────────────────────────────────────────────

- Մուտք admin-ի համար (admin / admin123)
- Admin-ը տեսնում է.
  - Ընդհանուր վիճակագրություն (ուսուցիչներ, դասարաններ, աշակերտներ)
  - Ուսուցիչների ցանկը
  - Դասարանների ցանկը
  - Դասացուցակը
  - Աշակերտների ցանկը (ըստ դասարանի)

─────────────────────────────────────────────
2. 👨‍🏫 ՈՒՍՈՒՑԻՉՆԵՐԻ ԿԱՌԱՎԱՐՈՒՄ
─────────────────────────────────────────────

- [Հրավիրել ուսուցիչ] կոճակ
  - Անուն, Ազգանուն, Էլ.փոստ, Առարկա
  - [Պահպանել] → ուսուցիչը ավելանում է

- Ցուցակ (բոլոր ուսուցիչները)
  - Անուն, Ազգանուն, Առարկա
  - [Խմբագրել] → փոխել տվյալները
  - [Ջնջել] → հեռացնել ուսուցչին

─────────────────────────────────────────────
3. 📚 ԴԱՍԱՐԱՆՆԵՐԻ ԿԱՌԱՎԱՐՈՒՄ
─────────────────────────────────────────────

- [Ստեղծել դասարան] կոճակ
  - Դասարանի անուն (օր. 7-1)
  - Դասարան (օր. 7-րդ)
  - Ուսուցիչ (ընտրել ցանկից)
  - [Պահպանել] → դասարանը ստեղծվում է

- Ցուցակ (բոլոր դասարանները)
  - Անուն, Դասարան, Ուսուցիչ, Աշակերտների քանակ
  - [Խմբագրել] → փոխել տվյալները
  - [Ջնջել] → հեռացնել դասարանը

─────────────────────────────────────────────
4. 📅 ԴԱՍԱՑՈՒՑԱԿԻ ԿԱՌԱՎԱՐՈՒՄ
─────────────────────────────────────────────

- [Ավելացնել դաս] կոճակ
  - Օր (Երկուշաբթի, Երեքշաբթի...)
  - Ժամ (08:00, 09:00...)
  - Առարկա
  - Դասարան (ընտրել ցանկից)
  - [Պահպանել] → դասը ավելանում է

- Ցուցակ (բոլոր դասերը)
  - Օր, Ժամ, Առարկա, Դասարան
  - [Խմբագրել] → փոխել տվյալները
  - [Ջնջել] → հեռացնել դասը

─────────────────────────────────────────────
5. 👨‍🎓 ԱՇԱԿԵՐՏՆԵՐԻ ԿԱՌԱՎԱՐՈՒՄ
─────────────────────────────────────────────

- Ընտրել դասարան (dropdown)
- [Ավելացնել աշակերտ] կոճակ
  - Անուն, Ազգանուն, Օգտանուն, Գաղտնաբառ
  - [Պահպանել] → աշակերտը ավելանում է

- Ցուցակ (դասարանի աշակերտները)
  - Անուն, Ազգանուն
  - [Հեռացնել] → աշակերտին դասարանից հեռացնել

7. API
─────────────────────────────────────────────

- GET /api/admin/teachers — բոլոր ուսուցիչները
- POST /api/admin/teachers — ավելացնել ուսուցիչ
- PUT /api/admin/teachers/:id — խմբագրել ուսուցիչ
- DELETE /api/admin/teachers/:id — ջնջել ուսուցիչ

- GET /api/admin/classes — բոլոր դասարանները
- POST /api/admin/classes — ստեղծել դասարան
- PUT /api/admin/classes/:id — խմբագրել դասարան
- DELETE /api/admin/classes/:id — ջնջել դասարան

- GET /api/admin/schedule — բոլոր դասերը
- POST /api/admin/schedule — ավելացնել դաս
- PUT /api/admin/schedule/:id — խմբագրել դաս
- DELETE /api/admin/schedule/:id — ջնջել դաս

- GET /api/admin/students/:class_id — դասարանի աշակերտները
- POST /api/admin/students — ավելացնել աշակերտ
- DELETE /api/admin/students/:id — հեռացնել աշակերտ
