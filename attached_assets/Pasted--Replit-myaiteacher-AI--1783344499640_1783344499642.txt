Ստեղծիր ամբողջական վեբ հավելված Replit-ում՝ «myaiteacher — Քո անձնական AI ուսուցիչը» անվամբ:

─────────────────────────────────────────────
1. 🏗️ BACKEND (Node.js + Express կամ Python + Flask)
─────────────────────────────────────────────

Ընտրիր այն, ինչ ավելի հարմար է Replit-ի համար:

- SQLite տվյալների բազա
- 2 աղյուսակ.
  1. users (id, username, password_hash, full_name, created_at)
  2. student_progress (id, user_id, subject, lesson, score, status)

- Register (POST /api/register) — username, password, full_name
- Login (POST /api/login) — username, password → JWT token
- Profile (GET /api/profile) — JWT-ով ստուգում
- Dashboard data (GET /api/dashboard) — վիճակագրություն, առարկաներ, առաջընթաց
