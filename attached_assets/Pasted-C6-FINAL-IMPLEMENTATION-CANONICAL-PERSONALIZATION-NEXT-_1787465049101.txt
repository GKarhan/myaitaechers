3. CANONICAL NEXT COGNITIVE LEVEL RESOLVER
════════════════════════════════════════════════════

Implement one deterministic resolver based on:

accepted C2 path order
+
C4 demonstrated ceiling.

IMPORTANT:

Use Cognitive Level identity + accepted path sequence.

DO NOT assume:

REMEMBER = 1
UNDERSTAND = 2
APPLY = 3
etc.

Do not use Bloom numeric comparison as path identity.

RULE A — NO DEMONSTRATED CEILING

If demonstratedCognitiveLevelId == null:

nextTargetCognitiveLevelId =
FIRST accepted level in the C2 path.

RULE B — DEMONSTRATED LEVEL EXISTS BELOW TARGET

Find demonstrated level inside the accepted path.

nextTargetCognitiveLevelId =
FIRST accepted level AFTER demonstrated level.

Example:

accepted path:

UNDERSTAND
→ APPLY
→ ANALYZE

demonstrated:

UNDERSTAND

result:

APPLY

RULE C

accepted path:

UNDERSTAND
→ APPLY
→ ANALYZE

demonstrated:

APPLY

result:

ANALYZE

RULE D — TARGET DEMONSTRATED

If the accepted curriculum target is already demonstrated:

do not invent a higher Cognitive Level.

C5 should normally classify this as MASTERED.

C6 then decides REVIEW or ADVANCE depending on entry intent.

RULE E — PATH STARTS ABOVE REMEMBER

Example:

UNDERSTAND
→ APPLY

The learner MUST start at UNDERSTAND.

Never insert REMEMBER.

RULE F — INVALID / UNACCEPTED PATH

Fail closed for cognitive-level targeting.

Do not silently use legacy Bloom fallback as the canonical C6 target.

Return an explicit deterministic reason/status so the caller can safely
handle the unavailable C6 target.
