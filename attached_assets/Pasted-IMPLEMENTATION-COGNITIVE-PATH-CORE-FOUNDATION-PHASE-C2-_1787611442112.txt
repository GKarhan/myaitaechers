==================================================

Implement/strengthen one lesson-level orchestrator.

1. Load eligible canonical MicroNodes for the lesson.

- MISSING

- IN_PROGRESS
- SKIPPED_PROTECTED

- confirmed paths
- teacher-authored paths

NOT:
entire operation rolled back

and NOT:
failed nodes silently disappear.

==================================================

Prevent duplicate simultaneous generation for the same MicroNode.

last-write-wins replacement.

Use existing job/locking/idempotency architecture if available.

→ no second provider call for same generation unit

Lesson bulk action and individual node generation must respect the same protection.

Do NOT introduce heavy distributed infrastructure if unnecessary.

Use the smallest reliable mechanism available in the repository.
