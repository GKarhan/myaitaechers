# 10. SEQUENCE NORMALIZATION — REQUIRED

After reorder, backend must persist normalized values:

`1, 2, 3, 4, ...`

NOT:

`1, 7, 12, 19`

Do not rely solely on frontend ordering.

Backend must validate/normalize the order being persisted.

Prefer a transactional operation.

A reorder should behave atomically:

either the complete new order is committed,

or the previous order remains.

Do not leave partially updated sequences if one DB write fails.
