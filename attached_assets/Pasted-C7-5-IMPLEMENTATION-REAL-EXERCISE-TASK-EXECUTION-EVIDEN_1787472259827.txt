==================================================
5. TASK TYPE ≠ EVIDENCE STRENGTH
==================================================

Do NOT hard-code:

multiple choice = WEAK
constructed response = STRONG

or similar universal rules.

C3 evidence quality depends on:

- cognitive alignment
- success criterion coverage
- independence
- task diagnostic quality
- learner response.

Preserve those semantics.

Task type may be an input.

It is not the final evidence strength authority.

==================================================
6. MICRO-CHECK VS REAL EXERCISE
==================================================

Keep these separate.

MICRO_CHECK:

- short instructional check
- tied to just-taught content
- C7.2 stage-managed
- evidence cap remains ≤ MODERATE where current contract requires

REAL EXERCISE:

- approved/eligible task or bounded equivalent
- can produce stronger canonical evidence if C3 requirements are met.

A micro-check must never be relabeled as a real exercise simply because
the learner answered correctly.

response is evaluated.

Do not store only raw text with no identity.

9. INDEPENDENT RE-CHECK SAFETY
==================================================

C7.4 established:

assisted success
→ new equivalent independent re-check.

C7.5 must enforce task identity safety.

The independent re-check must NOT be:

==================================================
10. ATTEMPT IDENTITY
==================================================

Task and attempt are different concepts.

One task can have multiple attempts.

Each evaluable learner response should have a traceable attempt identity
or deterministic equivalent existing mechanism.

Do not overwrite historical attempts.

Do not use the same attempt identity for two separate submissions.

Duplicate submission of the SAME response/retry must not create a second
attempt/evidence event.

Reuse C7.4 reservation/idempotency hardening.

==================================================

==================================================

Do not re-fetch a changed exercise version and evaluate against that.

Do not let current session target replace the historical task target if
they differ due to transition/recovery.

C7.2/C7.3 recovery snapshots remain authoritative for that turn.
