Phase 5 forensic report-ը ընդունում եմ որպես հիմք։ Հիմա միանգամից բոլոր P5.x փոփոխությունները մի արա։

Աշխատի՛ր առաջին հերթին միայն այս 3 կետերի վրա՝

### P5.1 — EXERCISE/ACTIVITY/HOMEWORK → sourceBlockIndices detection

Ստուգիր Pass 2-ի վերջնական արդյունքը և գտիր բոլոր դեպքերը, երբ իրական student-facing activity block-ը հայտնվում է `sourceBlockIndices`-ում, ոչ թե `exercises[]` / `additionalExercises[]`-ում։

Flag արա առնվազն՝

* EXERCISE
* ACTIVITY
* HOMEWORK

Review item-ը պետք է ցույց տա՝

* blockIndex
* blockType
* MicroNode
* source text-ի կարճ preview
* severity = HIGH

Սա պետք է լինի additive validation և չփոխի mapping-ը։

### P5.4 — unmappedBlocks-ում իրական exercise-ի detection

`unmappedBlockIndices`-ի յուրաքանչյուր block-ի համար ստուգիր original Pass 1 block-ը։

Եթե `blockType` = EXERCISE / ACTIVITY / HOMEWORK, դա պետք է HIGH review item առաջացնի։

Ավելին՝ նման exercise-ը չպետք է silently disappear անի։

Եթե անվտանգ է առանց սխալ node assignment-ի, պահպանիր այն որպես unassigned/additional exercise։ Բայց **չվերագրես պատահական MicroNode-ի**։

Header/structural NOTE block-երը թող մնան unmapped։

### P5.6 — EXERCISE → theory prompt hardening

`PASS2_STEP2_SYSTEM`-ում հանիր/խստացրու այս ambiguous կանոնը՝

> "EXERCISE blocks that form a theoretical list/enumeration"

Սահմանիր հստակ կանոն.

Եթե EXERCISE block-ը student-ից պահանջում է գործողություն՝ օրինակ՝

* գտնել
* հաշվել
* լրացնել
* բացատրել
* համեմատել
* գրել
* որոշել
* լուծել
* դասակարգել
* կազմել

ապա այն **պարտադիր exercises[] է** և երբեք չի կարող հայտնվել `sourceBlockIndices`-ում։

`sourceBlockIndices`-ում EXERCISE կարող է հայտնվել միայն այն դեպքում, եթե այն փաստացի student task չէ և պարունակում է միայն տեսական enumeration/information։
