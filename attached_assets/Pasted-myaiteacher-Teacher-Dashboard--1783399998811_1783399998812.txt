myaiteacher-ում ավելացրու Teacher Dashboard-ը բոլոր ֆունկցիաներով:

─────────────────────────────────────────────
1. 👨‍🏫 TEACHER DASHBOARD
─────────────────────────────────────────────

- Մուտք teacher-ի համար (teacher1 / teacher123)
- Teacher-ը տեսնում է.
  - Իր դասացուցակը (օր, ժամ, առարկա, դասարան)
  - Իր դասարանները (ցուցակ)
  - Յուրաքանչյուր դասարանի աշակերտներին
  - Աշակերտների առաջընթացը

─────────────────────────────────────────────

- [Սկսել] կոճակ → տանում է դասի էջ

10. API
─────────────────────────────────────────────

- GET /api/teacher/dashboard — teacher-ի բոլոր տվյալները
- GET /api/teacher/classes — teacher-ի դասարանները
- GET /api/teacher/class/:id — դասարանի տվյալները
- GET /api/teacher/students/:class_id — դասարանի աշակերտները
- POST /api/teacher/resources — կցել ռեսուրս
- POST /api/teacher/lessons/generate — AI-ով գեներացնել դասեր
- POST /api/teacher/lessons — ձեռքով ստեղծել դաս
- PUT /api/teacher/lessons/:id — խմբագրել դաս
- DELETE /api/teacher/lessons/:id — ջնջել դաս
- POST /api/teacher/homework — տալ տնային
- POST /api/teacher/homework/:id/grade — գնահատել

12. DATABASE
─────────────────────────────────────────────

- users (id, username, password, full_name, role)
- teachers (id, user_id, subject)
- classes (id, name, grade, teacher_id)
- class_students (id, class_id, student_id)
- schedule (id, class_id, day, time, subject)
- books (id, class_id, name, file_path)
- curriculum (id, class_id, name, file_path, total_lessons, total_hours)
- lessons (id, class_id, lesson_number, title, pages, month, day, duration, knowledge_tree)
- homework (id, lesson_id, student_id, task, answer, score, feedback, status)

13. 📌 ՊԱՀԱՆՋՆԵՐ
