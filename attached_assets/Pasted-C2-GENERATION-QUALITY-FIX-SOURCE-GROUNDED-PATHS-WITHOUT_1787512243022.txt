==================================================
3. IMPROVE C2 GENERATION FOR SOURCE-SUFFICIENT NODES
==================================================

For source-sufficient MicroNodes, strengthen the canonical C2 generator.

Every generated:

- Cognitive Level
- Performance Objective
- Success Criterion

must be directly supportable by:

MicroNode learning objective
+
MicroNode source content
+
existing C1 target ceiling.

Rules:

1. Do not introduce facts, procedures, examples, comparisons, numeric
   claims, or conceptual extensions not present or clearly entailed by
   the source.

2. Do not make a Success Criterion broader than the source.

3. Do not use generic Bloom boilerplate that adds unsupported operations.

4. Preserve the exact C1 target ceiling.
   Never elevate the path beyond it.

5. Lower levels may only be included when they are pedagogically valid
   prerequisites inside the accepted C1/C2 semantics.

6. A path may begin above REMEMBER.
   Never invent REMEMBER merely because it is the first Bloom level.

==================================================
4. SOURCE-ANCHORED PERFORMANCE OBJECTIVES
==================================================

Performance Objectives must describe what the learner can demonstrate
WITH THE KNOWLEDGE PRESENT IN THIS MICRONODE.

Bad pattern:

source describes representation of a number as place-value addends
→ generated criterion introduces unrelated operations or concepts.

Good pattern:

source explicitly demonstrates:
7254 = 7000 + 200 + 50 + 4

Then a grounded criterion can ask the learner to correctly represent a
given number as a sum of its place-value addends.

The wording may be new.
The curriculum claim may not be new.

==================================================
5. SOURCE-ANCHORED SUCCESS CRITERIA
==================================================

Success Criterion must be:

- observable
- assessable
- narrow enough
- source-supported
- aligned to the current Cognitive Level

Do not use broad generic criteria such as:

"analyzes properties"
"explains relationships"
"solves different problems"

unless the source/objective actually supports those operations.

==================================================
6. DO NOT FORCE ENRICHMENT
==================================================

If a source only supports one valid Cognitive Level:

generate ONE valid level.

That is better than inventing:

Remember → Understand → Apply → Analyze

without evidence.

C2 richness is not a goal by itself.

SOURCE-ALIGNED PATH QUALITY is the goal.
