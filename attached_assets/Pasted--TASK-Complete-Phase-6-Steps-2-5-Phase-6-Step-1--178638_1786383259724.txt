# STEP 3 — Additional Exercises UI

Teacher Review-ի LessonNodesPanel-ում ավելացրու առանձին բաժին.

### «📦 Լրացուցիչ վարժություններ»

Այստեղ պետք է երևան **բոլոր exercises-ները, որոնց**

```text
relatedNodeId === null
```

Այսինքն՝ ոչ մի MicroNode-ի չկցված վարժությունները երբեք չպետք է կորչեն։

Յուրաքանչյուր exercise պետք է ցույց տա առնվազն.

* exercise number / title
* exercise content
* block type
* էջը, եթե կա
* edit button
* delete button
* «Կցել նոդին» գործողություն

Բաժինը կարող է լինել collapsed/expandable։

Եթե `additionalExercises = 0`, ցույց տուր համապատասխան empty state։

# STEP 4 — Move Exercise Between Nodes

Exercise edit UI-ում ավելացրու.

### «Կցել նոդին»

Dropdown-ը պետք է պարունակի.

```text
Չկցված / Լրացուցիչ վարժություն
MicroNode 1 — [title]
MicroNode 2 — [title]
MicroNode 3 — [title]
...
```

Teacher-ը պետք է կարողանա.

```text
Node A → Node B
Node A → Additional Exercises
Additional Exercises → Node C
```

Օգտագործիր արդեն գոյություն ունեցող `relatedNodeId` update API-ն, եթե այն արդեն աշխատում է։

**Նոր API route մի ստեղծիր, եթե անհրաժեշտ չէ։**

Պահպանիր `relatedNodeId = null` semantics-ը՝ որպես Additional Exercise։

### Կարևոր invariant

Exercise-ը միշտ պետք է մնա տեսանելի ինչ-որ տեղ.

```text
relatedNodeId !== null
        → համապատասխան MicroNode-ի exercises[]

relatedNodeId === null
        → Additional Exercises
```

Ոչ մի exercise չպետք է անհետանա UI-ից։

# Important architectural rules

1. **Մի փոխիր Pass 1-ը։**
2. **Մի փոխիր Pass 2 exercise assignment logic-ը։**
3. **Մի փոխիր `normalizeActivityPlacements()`-ը։**
4. **Մի սկսիր Phase 7 Dependencies։**
5. **Մի ավելացրու նոր DB columns։**
6. **Մի ջնջիր legacy Phase 2 columns։**
7. `relatedNodeId = null` նշանակում է Additional Exercise։
8. Բոլոր exercises-ը պետք է հասանելի լինեն UI-ում։
9. Teacher-ը պետք է կարողանա ցանկացած exercise տեղափոխել ցանկացած MicroNode կամ վերադարձնել Additional Exercises։
10. Բոլոր հիմնական mapping/theory fields-ը պետք է editable լինեն։
11. Lesson overview-ը պետք է editable լինի։
12. Lesson overview-ը պետք է հասանելի լինի AB Teacher-ին որպես `LESSON_OVERVIEW`։
13. Existing tests-ը չպետք է կոտրվեն։

# Implementation discipline

Սկզբում **audit արա միայն անհրաժեշտ files-ը** և հստակ ցույց տուր՝ ինչ ես պատրաստվում փոխել։

Հետո իրականացրու Step 2–5-ը։

Յուրաքանչյուր քայլից հետո ստուգիր build/tests։

Վերջում պարտադիր ստուգիր իրական lesson-ի վրա.

* բոլոր MicroNodes երևո՞ւմ են
* node theory-ն երևո՞ւմ և խմբագրվո՞ւմ է
* բոլոր exercises-ները երևո՞ւմ են
* `relatedNodeId = null` exercises-ը երևո՞ւմ են Additional Exercises-ում
* exercise-ը հնարավոր է՞ տեղափոխել node
* node-ից Additional տեղափոխելը աշխատո՞ւմ է
* lesson overview-ը պահպանվո՞ւմ է
* lesson overview-ը AB Teacher context մտնո՞ւմ է
* existing exercise-assignment tests-ը մնում են անցած
