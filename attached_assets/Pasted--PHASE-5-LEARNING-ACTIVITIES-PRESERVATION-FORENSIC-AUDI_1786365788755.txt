# PHASE 5 — LEARNING ACTIVITIES PRESERVATION — FORENSIC AUDIT

## READ-ONLY — NO CODE CHANGES

You are now auditing **Phase 5 — Learning Activities Preservation** of the textbook mapping pipeline.

Do NOT modify code, prompts, schemas, database records, or UI.
Do NOT implement any fix.
Do NOT create a migration.
Do NOT change existing mappings.

Your task is to perform a **forensic, evidence-based audit** of whether real textbook learning activities are reliably preserved from source textbook → extraction → mapping → MicroNode → database → AI Teacher.

The core contract is:

> If the textbook contains a real learning activity, it must not be silently lost merely because the AI interprets it as an example, explanation, note, or supporting text.

The mapping pipeline must reliably distinguish and preserve:

* EXPLANATION
* EXAMPLE
* EXERCISE
* QUESTION
* ACTIVITY
* TASK
* PRACTICE

The goal is NOT to force every numbered sentence into an exercise.

The goal is to ensure that a **real student-facing activity/question/task/practice item present in the textbook survives the mapping pipeline** and is attached to the correct MicroNode or preserved as an appropriate unmapped/additional activity when no valid MicroNode exists.

# 22. IMPORTANT DESIGN PRINCIPLE

The final recommendation must preserve this distinction:

> **SOURCE COVERAGE ≠ LEARNING ACTIVITY PRESERVATION**

A source block can be covered while the actual student task is lost.

The Phase 5 gate must therefore independently answer:

> "Did every real student-facing learning activity in the textbook survive the mapping pipeline in a usable form?"

Do not recommend making every EXERCISE a MicroNode.

Do not recommend forcing unmatched exercises onto the nearest MicroNode.

Do not recommend treating every numbered example as an exercise.

The goal is **lossless activity preservation with semantically correct assignment**, not maximum exercise-to-node assignment.
