═══════════════════════════════════════════════════
ERRORS VS WARNINGS
═══════════════════════════════════════════════════

ERROR — blocks AI Teacher readiness:

- invalid source coverage
- lost activity
- duplicate persisted source activity
- zero MicroNodes
- empty required MicroNode content
- invalid sequence
- approved node missing required Phase 2 content
- invalid dependency reference
- self dependency
- duplicate dependency edge if structurally invalid
- dependency cycle
- unresolved approval state that existing contract says is blocking

WARNING — does NOT necessarily block:

- activity remains in Additional Exercises
- node has no directly assigned exercise
- optional Phase 2 fields are absent
- no dependency exists where sequence alone is sufficient
- other non-mandatory metadata absent

Do not convert warnings into errors without evidence from the existing
contract.
