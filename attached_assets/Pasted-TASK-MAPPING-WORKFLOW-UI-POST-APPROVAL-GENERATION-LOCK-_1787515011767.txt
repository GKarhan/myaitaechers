==================================================
8. DO NOT ALLOW ACCIDENTAL REGENERATION
==================================================

A normal teacher workflow must NOT allow:

Create Cognitive Paths
→ review
→ accidentally click regenerate
→ overwrite valid paths.

Or:

Create Teaching Content
→ review
→ accidentally regenerate
→ overwrite valid teacher-reviewed content.

Existing backend protection against teacher-edited/confirmed content
must remain fail-closed.

Never use force=true or equivalent automatic overwrite.
