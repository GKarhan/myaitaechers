myaiteacher-ում ավելացրու գիրք կցելու և դասերի ավտոմատ գեներացման ֆունկցիան:

─────────────────────────────────────────────
1. 📚 ԳԻՐՔ ԿՑԵԼ (Book Upload)
─────────────────────────────────────────────

- Student Dashboard-ում ավելացնել «Իմ գրքերը» բաժին
- [Կցել գիրք] կոճակ (PDF, Word, TXT)
- Ֆայլը վերբեռնվում և պահվում է /uploads պանակում
- Տվյալների բազայում պահվում է գրքի անունը, ուղին, ամսաթիվը
- Ցուցադրվում է կցված գրքերի ցանկը

─────────────────────────────────────────────
2. 📖 ԳԻՐՔԸ ԱՌԱՐԿԱՅԻ ԷՋՈՒՄ
─────────────────────────────────────────────

- Subject Detail-ում ցուցադրվում է կցված գիրքը
- Գրքի անունը, չափը, ամսաթիվը
- [Փոխել գիրք] կոճակ (նորը վերբեռնելու համար)

─────────────────────────────────────────────
3. 🤖 ԴԱՍԵՐԻ ԱՎՏՈՄԱՏ ԳԵՆԵՐԱՑՈՒՄ
─────────────────────────────────────────────

- Subject Detail-ում ավելացնել [Գեներացնել դասեր] կոճակ
- AI-ն (OpenRouter / DeepSeek) վերլուծում է գրքի բովանդակությունը
- Ստեղծում է դասեր (ըստ գրքի թեմաների և բաժինների)
- Յուրաքանչյուր դասի համար ստեղծում է Knowledge Tree (6 մակարդակ)
- Դասերը պահվում են տվյալների բազայում (lessons աղյուսակ)

─────────────────────────────────────────────
4. 🧠 SYSTEM PROMPT (ԴԱՍԵՐԻ ԳԵՆԵՐԱՑՄԱՆ ՀԱՄԱՐ)
─────────────────────────────────────────────

"Դու myaiteacher-ի AI օգնականն ես:
- Վերլուծում ես տրված գրքի բովանդակությունը
- Բաժանում ես թեմաների (ըստ գլուխների կամ բաժինների)
- Յուրաքանչյուր թեմայի համար ստեղծում ես դաս
- Յուրաքանչյուր դասի համար ստեղծում ես Knowledge Tree (6 մակարդակ՝ Բլումի տաքսոնոմիայով)
- Դասերը ներկայացնում ես JSON ձևաչափով"

─────────────────────────────────────────────
5. API
─────────────────────────────────────────────

- POST /api/books/upload — գիրք վերբեռնել
- GET /api/books — բոլոր գրքերը
- GET /api/books/:id — կոնկրետ գիրք
- POST /api/books/:id/generate-lessons — դասեր գեներացնել

─────────────────────────────────────────────
6. FRONTEND
─────────────────────────────────────────────

- books.html (կամ Books.jsx) — «Իմ գրքերը» էջ
- subject.html-ում ավելացնել գրքի ցուցադրում
- subject.html-ում ավելացնել [Գեներացնել դասեր] կոճակ
- Loading / Progress ցուցիչ գեներացման ժամանակ

─────────────────────────────────────────────
7. DATABASE
─────────────────────────────────────────────

- books աղյուսակ (id, user_id, subject_id, name, file_path, size, uploaded_at)
- lessons աղյուսակ (id, subject_id, title, content, knowledge_tree, status)

─────────────────────────────────────────────
8. 📌 ՊԱՀԱՆՋՆԵՐ
─────────────────────────────────────────────

- Ֆայլի չափը ≤ 10MB (PDF, Word, TXT)
- AI-ն աշխատում է OpenRouter-ի միջոցով
- Դասերը գեներացվում են հայերեն
- Knowledge Tree-ն ներառում է 6 մակարդակ

─────────────────────────────────────────────
9. 🚀 ՏՐԱՄԱԴՐԻՐ ԱՄԲՈՂՋԱԿԱՆ ԿՈԴԸ
─────────────────────────────────────────────

- Backend (book routes, file upload, AI service)
- Frontend (books.html, subject.html-ի թարմացում)
- Database (books աղյուսակ, lessons-ի թարմացում)
- System Prompt-ը ներառված է
- OpenRouter-ի ինտեգրումը պահպանված է
