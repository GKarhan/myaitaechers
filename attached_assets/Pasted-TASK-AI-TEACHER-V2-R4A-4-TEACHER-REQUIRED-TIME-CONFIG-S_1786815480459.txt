6. COUNTDOWN BEHAVIOR
==================================================

The frontend may decrement its DISPLAY timer once per second for smooth
visual feedback.

But:

FRONTEND TIMER MUST NOT:
- write mastery;
- create evidence;
- end the session by itself;
- mark failure;
- advance MicroNodes;
- invoke END_REQUIRED_SESSION by itself.

Backend remains authoritative.

On every successful chat response, synchronize the displayed timer
from the authoritative backend:

remainingRequiredSeconds

This corrects frontend drift.

Also synchronize from currentSession on:
- initial page load;
- refresh;
- resume.
