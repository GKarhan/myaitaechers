─────────────────────────────────────────────

- Մուտք admin-ի համար (admin / admin123)
- Ֆունկցիաներ.
  - 📋 Ուսուցիչների կառավարում.
    - [Ավելացնել ուսուցիչ] (անուն, ազգանուն, էլ.փոստ, առարկա)
    - [Ցուցակ] բոլոր ուսուցիչները
    - [Խմբագրել] / [Ջնջել] ուսուցիչ
  - 📚 Դասարանների կառավարում.
    - [Ստեղծել դասարան] (անուն, դասարան, ուսուցիչ)
    - [Ցուցակ] բոլոր դասարանները
    - [Խմբագրել] / [Ջնջել] դասարան
  - 👨‍🎓 Աշակերտների կառավարում (ըստ դասարանի)
  - 📊 Ընդհանուր վիճակագրություն (ուսուցիչներ, դասարաններ, աշակերտներ)

2. 👨‍🏫 TEACHER DASHBOARD
─────────────────────────────────────────────

- Մուտք teacher-ի համար (teacher1 / teacher123)
- Ֆունկցիաներ.
  - 📚 Իմ դասարանները (ցուցակ)
  - 👨‍🎓 Աշակերտների կառավարում (ավելացնել, ջնջել, խմբագրել)
  - 📖 Դասագրքեր (կցել, ջնջել)
  - 📝 Դասերի ստեղծում (ըստ գրքի կամ ձեռքով)
  - 📊 Աշակերտների առաջընթաց (տեսնել յուրաքանչյուր աշակերտի)
  - 🏠 Տնային աշխատանք (տալ, գնահատել)

─────────────────────────────────────────────
3. 🔗 ԿԱՊԸ STUDENT-Ի ՀԵՏ
─────────────────────────────────────────────

- Ուսուցիչը ստեղծում է դասարան → ավելացնում է աշակերտներ
- Ուսուցիչը ավելացնում է դասագիրք → աշակերտը տեսնում է
- Ուսուցիչը ստեղծում է դասեր → աշակերտը տեսնում է
- Ուսուցիչը գնահատում է տնայինը → աշակերտը տեսնում է

─────────────────────────────────────────────
4. API
─────────────────────────────────────────────

- GET /api/admin/teachers — բոլոր ուսուցիչները
- POST /api/admin/teachers — ավելացնել ուսուցիչ
- DELETE /api/admin/teachers/:id — ջնջել ուսուցիչ
- GET /api/admin/classes — բոլոր դասարանները
- POST /api/admin/classes — ստեղծել դասարան
- GET /api/teacher/students — աշակերտների ցանկ (ուսուցչի համար)
- POST /api/teacher/students — ավելացնել աշակերտ
- POST /api/teacher/books — գիրք կցել
- POST /api/teacher/lessons — դաս ստեղծել

─────────────────────────────────────────────
