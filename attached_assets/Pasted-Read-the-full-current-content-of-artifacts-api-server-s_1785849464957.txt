## Goal
After a lesson is mapped (lesson_nodes created), automatically create
knowledge_nodes rows (status="not_started", no scores) for every student
currently enrolled in the class this lesson's course belongs to — so the
Knowledge Tree shows the full node map immediately, before any quiz is
taken.

## Step 2 — Implement eager creation at the end of the map handler
Right after lesson_nodes (and lesson_node_dependencies) are inserted in
POST /lessons/:lessonId/map, add a step that:
1. Resolves the lesson's courseId → the course's classId → all
   classStudentsTable.studentId for that class
2. For each (student, lesson_node) pair, insert a knowledge_nodes row:
   subjectId = lesson.subjectId, userId = student, topicName =
   lessonNode.title, lessonNodeId = lessonNode.id, status = "not_started",
   isProvisional = true, bloomLevel = lessonNode.targetBloomLevel,
   masteryScore/confidenceScore/retentionScore = null
3. Must be idempotent — if a knowledge_nodes row for that
   (userId, lessonNodeId) pair already exists (e.g. from a re-map or a
   prior quiz submission), skip it, don't create a duplicate or overwrite
   existing scores. Use an existence check or ON CONFLICT DO NOTHING if a
   unique constraint on (userId, lessonNodeId) exists — check the schema
   first; if no such unique constraint exists, add one via drizzle-kit
   push before relying on ON CONFLICT.
4. Wrap this in the same request as the node-mapping insert (or a
   follow-up transaction) so it can't silently fail separately — log
   clearly how many knowledge_nodes rows were created vs skipped as
   already-existing.
