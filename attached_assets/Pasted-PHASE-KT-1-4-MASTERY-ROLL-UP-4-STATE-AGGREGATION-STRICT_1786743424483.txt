6. NOT_STARTED HANDLING — MUST BE EXPLICIT
==================================================

This is critical.

A subject with:

10 mastered nodes
90 not_started nodes

must NOT misleadingly appear as 100% mastered.

The roll-up must account for the full curriculum coverage.

Therefore explicitly decide how not_started contributes.

Do not hide unstudied curriculum from the denominator unless you can justify that with the product model.

Report the chosen semantics in plain language.

The desired product interpretation is generally:

"Յուրացում" = how much of the currently visible curriculum the student has mastered

not merely:

"average score among the nodes they happened to attempt."

==================================================
8. RECOMMENDED V1 DIRECTION — VALIDATE, DO NOT BLINDLY APPLY
==================================================

Evaluate whether the cleanest V1 formula is:

For each visible atomic MicroNode:

effectiveMastery =
- masteryScore if learner state exists
- 0 if not_started / no learner state

Parent mastery % =
round(
  sum(effectiveMastery for child atomic nodes)
  /
  number of visible atomic nodes
)

This means every atomic MicroNode has equal curriculum weight.

Example:

MicroNode A = 100
MicroNode B = 67
MicroNode C = 0
MicroNode D = not_started → 0

Parent =
(100 + 67 + 0 + 0) / 4
= 41.75%
→ 42%

This is only a candidate.

Before implementing, audit whether any existing product rule conflicts with it.
