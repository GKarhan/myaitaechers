myaiteacher-ում ավելացրու դասի էջը և AI Tutor-ը (Chat + DeepSeek API):

─────────────────────────────────────────────
1. 📖 ԴԱՍԻ ԷՋ (Lesson Page)
─────────────────────────────────────────────

- Դասի վերնագիր + առարկա
- Բովանդակություն (տեքստ, նկարներ)
- Knowledge Tree (6 մակարդակ)
  🟢 Level 1 (Հիշել)
  🟡 Level 2 (Հասկանալ)
  🟡 Level 3 (Կիրառել)
  🟠 Level 4 (Վերլուծել)
  🔴 Level 5 (Գնահատել)
  🔴 Level 6 (Ստեղծել)

- [Սկսել դասը] կոճակ (8 փուլ)

─────────────────────────────────────────────
2. 🤖 AI TUTOR (CHAT)
─────────────────────────────────────────────

- Chat ինտերֆեյս (հաղորդագրություններ, մուտք, ուղարկել)
- DeepSeek API-ի միացում
- System Prompt (Սոկրատյան մեթոդ, հայերեն)
- AI-ն պատասխանում է հայերեն
- Յուրաքանչյուր հաղորդագրություն պահվում է SQLite-ում

─────────────────────────────────────────────
3. 🚀 ԴԱՍԻ 8 ՓՈՒԼ
─────────────────────────────────────────────

1. Կրկնություն (5 րոպե)
2. Հիմնական գաղափարներ (8-10 րոպե)
3. Երկրորդական գաղափարներ (7-8 րոպե)
4. Գործնական կիրառություն (8-10 րոպե)
5. Ստեղծագործական աշխատանք (8-10 րոպե)
6. Միկրո նախագիծ (10-12 րոպե)
7. Ամփոփում (5 րոպե)
8. Տնային (3 մակարդակ)

─────────────────────────────────────────────
4. API
─────────────────────────────────────────────

- POST /api/chat
  - Input: {message, student_id, lesson_id}
  - Output: {response, profile}

- GET /api/lesson/:id — դասի բովանդակություն
- POST /api/lesson/start — սկսել դասը (8 փուլ)

─────────────────────────────────────────────
5. DEEPSEEK API
─────────────────────────────────────────────

- .env ֆայլում DEEPSEEK_API_KEY
- API URL: https://api.deepseek.com/v1/chat/completions

─────────────────────────────────────────────
6. FRONTEND
─────────────────────────────────────────────

- lesson.html (կամ LessonDetail.jsx)
- chat.html (կամ Chat.jsx)
- 8 փուլերի ցուցադրում

─────────────────────────────────────────────
7. SYSTEM PROMPT (AI-ի հրահանգ)
─────────────────────────────────────────────

Դու myaiteacher-ի AI ուսուցիչն ես:
- Պատասխանում ես միայն հայերեն
- Օգտագործում ես Սոկրատյան մեթոդը (հարցերով առաջնորդում)
- Չես տալիս պատրաստի պատասխաններ
- Աշխատում ես միայն ներբեռնված դասագրքով

─────────────────────────────────────────────
8. ՏՐԱՄԱԴՐԻՐ ԱՄԲՈՂՋԱԿԱՆ ԿՈԴԸ
─────────────────────────────────────────────

- Backend (chat routes, AI service)
- Frontend (lesson.html, chat.html)
- System Prompt-ը ներառված է
