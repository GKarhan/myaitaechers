## PHASE 5 OBJECTIVE

Determine whether the Mapper's **source fidelity and pedagogical mapping output remain faithful after the MicroNode granularity stage**.

The central question is:

> After Pass 1 extraction → topic grouping → MicroNode generation → Phase 4 granularity review, does the final mapped knowledge base preserve the actual instructional meaning of the textbook?

We are specifically looking for failures where the Mapper technically produces valid MicroNodes but the resulting knowledge base is pedagogically or semantically distorted.

Do NOT assume that "source coverage = 100%" means source fidelity is correct.

Do NOT assume that a valid MicroNode automatically means the source content was mapped correctly.

# 4. SEMANTIC LOSS AUDIT

Look specifically for source content that disappears even though structural coverage passes.

Examples:

* a definition reduced to a vague title
* an exception omitted
* an important condition omitted
* a rule simplified incorrectly
* a counterexample lost
* a distinction between two concepts erased
* an example carrying important meaning treated as disposable
* a NOTE/IMPORTANT block not represented in any MicroNode
* a prerequisite statement lost during grouping
* a sequence/order relationship lost
* "only if", "except", "unless", "not", etc. omitted
* numerical constraints or conditions lost
* terminology changed in a way that changes meaning

For every finding provide:

* lesson/job
* source block index
* source text summary
* resulting MicroNode
* resulting LO
* exact semantic loss
* severity: HIGH / MEDIUM / LOW

# 5. DEFINITIONS / RULES / EXAMPLES / NOTES

Audit whether the Mapper correctly preserves the pedagogical role of each source type.

Specifically determine:

### DEFINITION

Does it become part of a MicroNode's teachable content?

### RULE

Does it remain explicit enough to teach and assess?

### EXAMPLE

Is it preserved as an example of the correct concept rather than accidentally becoming the learning objective?

### NOTE / IMPORTANT

Is important contextual information retained?

### OBJECTIVE

Is it mapped to the correct learning objective rather than duplicated or discarded?

### NON_EXAMPLE

Is it preserved when pedagogically important?

Identify any systematic failure.

# 6. TOPIC GROUPING AUDIT

Phase 4 checks MicroNode granularity, but it does not independently validate whether the original topic grouping was correct.

Audit Step 1 topic grouping.

Look for:

* unrelated source blocks grouped together
* one concept split across multiple topics
* prerequisite content separated from the concept it supports
* examples attached to the wrong topic
* exercises attached to the wrong topic
* two textbook sections that should remain separate being merged
* one textbook section incorrectly split into unrelated topics

This is important:

A perfect MicroNode inside a bad topic group is still a bad mapping.

Determine whether Step 1 needs its own semantic validation layer.

# 10. DUPLICATION / INFORMATION LOSS

Look for both:

### DUPLICATION

The same source meaning appears in multiple MicroNodes without justification.

### LOSS

A source meaning appears in no MicroNode.

These are different from Phase 4 OVER_SPLIT.

A source concept can be duplicated even when each MicroNode individually has a valid one-clear-learning-objective LO.

Identify examples from real DB data.
