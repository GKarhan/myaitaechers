# PART 4.3 — WRONG ANSWER → KNOWLEDGE STATE

Վերցրու առնվազն 3 սխալ պատասխան։

Յուրաքանչյուրի համար հետևիր.

`selected option`

→ `option_explanations[selectedOptionIndex]`

→ `question.node_id`

→ `evidence_event`

→ `knowledge_nodes`

→ `mastery_score`

→ `status`

Ստուգիր՝ արդյոք սխալ պատասխանը իրականում ազդում է ճիշտ Knowledge Node-ի վրա։

Հատկապես ստուգիր՝

* սխալ option-ը ճիշտ node-ին է գնում
* correct option-ը սխալ node չի ստեղծում
* նույն node-ի evidence-ը կուտակվում է
* տարբեր quiz-երի evidence-ը ճիշտ է կուտակվում
* historical evidence-ը չի կորում

# PART 4.6 — RECOMMENDATION PRIORITY

Ստուգիր recommendation sorting-ի իրական կանոնները։

Պարզիր՝ ինչու է համակարգը, օրինակ, առաջին տեղում դնում.

`Թվերի տրոհում աջից ձախ — Չգիտի`

իսկ հետո.

`Միլիոնների դասի ներածություն — Մասնակի գիտի`

Ստուգիր՝ priority-ն հիմնված է միայն mastery-ի վրա, թե նաև՝

* prerequisite
* dependency
* node order
* lesson sequence
* current lesson
* previous mastery
* evidence count
* status

Եթե dependency համակարգ կա, trace արա իրական տվյալով։

# PART 4.7 — PREREQUISITE / DEPENDENCY AUDIT

Կարդա և audit արա.

`lessonNodeDependencies`

և դրա օգտագործումը Personalized Learning-ի մեջ։

Հարցը.

Եթե աշակերտը չի տիրապետում prerequisite Node A-ին, բայց B-ն ավելի բարձր priority ունի, համակարգը ստիպո՞ւմ է սովորել A-ն նախ։

Ստեղծիր առնվազն մեկ իրական dependency chain.

`A → B → C`

և ցույց տուր՝

* A weak → ինչ recommendation է
* A mastered → B-ի հասանելիությունը
* B weak → C-ի հասանելիությունը

Եթե dependency-ն միայն DB-ում գոյություն ունի, բայց recommendation engine-ը չի օգտագործում, դա պետք է հստակ նշել։

# PART 4.10 — REAL PERSONALIZATION TEST

Օգտագործիր իրական quiz data և կառուցիր առնվազն 3 scenario։

## Scenario A — Weak student

Աշակերտը հիմնականում սխալ է պատասխանում Node A-ի հարցերին։

Ստուգիր՝

`A → low mastery → weak/not_started → targeted/full teaching`

արդյոք ճիշտ է։

---

## Scenario B — Mixed mastery

Աշակերտը.

* Node A = weak
* Node B = partial
* Node C = mastered

Ստուգիր՝ recommendation order-ը տրամաբանական է։

---

## Scenario C — Same node, different questions

Միևնույն node-ի տակ տարբեր հարցերի սխալներ։

Ստուգիր՝

* question-level feedback-ը տարբերակվո՞ւմ է
* mastery-ն node-level aggregate է
* համակարգը չի՞ պնդում, որ կոնկրետ sub-objective-ը չգիտի, եթե դրա համար առանձին evidence չկա

Սա հատկապես կարևոր է PART 3-ի granularity finding-ի պատճառով։
