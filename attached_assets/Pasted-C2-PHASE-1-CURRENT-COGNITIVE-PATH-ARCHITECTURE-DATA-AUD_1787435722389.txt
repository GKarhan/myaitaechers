==================================================
C2 PURPOSE
==================================================

C2 must define the pedagogically valid cognitive learning path for each
atomic MicroNode.

Canonical concept:

MicroNode
→ Cognitive Levels
→ Target Cognitive Level
→ Performance Objective
→ Success Criterion
→ Evidence Requirement Profile

Cognitive levels are based on the existing project taxonomy, such as:

Remember
Understand
Apply
Analyze
Evaluate
Create

but DO NOT assume every MicroNode needs every level.

A MicroNode may legitimately require only:

Remember → Understand

or:

Remember → Understand → Apply

or another source/outcome-grounded path.

The path must be determined by the knowledge objective and required
demonstrated performance.

==================================================
CRITICAL DISTINCTION
==================================================

C2 must distinguish:

1. CURRICULUM TARGET COGNITIVE LEVEL

What level the curriculum / canonical Outcome expects for this
MicroNode.

from:

2. LEARNER CURRENT DEMONSTRATED CEILING

What cognitive level a particular learner has actually demonstrated.

C2 defines the curriculum-side path and evidence requirements.

Learner-specific demonstrated ceiling belongs later to the Learner
Model / evidence pipeline.

Do NOT mix these concepts.

PART 10 — SOURCE GROUNDING
==================================================

C2 must not invent new curriculum knowledge.

Audit the current grounding rule:

MicroNode source
→ learningObjective
→ cognitive path

Important distinction:

Higher cognitive demand MAY transform how the learner demonstrates the
same knowledge.

It must NOT introduce new factual/conceptual knowledge absent from the
MicroNode.

For example:

Understand → Apply

may require applying the SAME concept in a new task.

That is legitimate.

But the generated Apply level must not introduce a different concept
that the MicroNode never teaches.

Determine whether current validation correctly distinguishes:

NEW COGNITIVE DEMAND

from:

NEW UNSUPPORTED KNOWLEDGE.

Report findings only.
