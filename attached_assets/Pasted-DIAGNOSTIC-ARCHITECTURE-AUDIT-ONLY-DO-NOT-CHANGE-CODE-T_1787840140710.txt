CANONICAL PRODUCT DECISION TO AUDIT AGAINST
==================================================

The quiz system must eventually test the knowledge structure produced by
lesson mapping.

For each MicroNode, the normal quiz should test ONLY that MicroNode's
highest / target mapped cognitive level.

Examples:

Understand
→ quiz tests Understand

Apply
→ quiz tests Apply

Understand → Apply
→ quiz tests Apply

Remember → Understand → Apply
→ quiz tests Apply

Understand → Apply → Analyze
→ quiz tests Analyze

The quiz should NOT automatically generate separate questions for all lower
Bloom levels.

Lower/path levels belong primarily to AI Teacher instruction:

MicroNode Cognitive Path
→ teach level
→ local micro-check
→ next mapped level
→ ...
→ target level

Therefore:

QUIZ =
"Has the learner demonstrated the MicroNode's target cognitive performance?"

AI TEACHER =
"Teach and locally verify the mapped path needed to reach that target."

Do NOT implement this decision in this task.
