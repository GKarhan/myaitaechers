# PART 9 — DO NOT MIX MANUAL EXERCISES WITH SOURCE COVERAGE

If teacher adds a manual exercise, total exercise count may increase.

Example:

Source exercises = 15

Teacher adds 1 manual exercise.

Total DB exercises may become 16.

This must NOT make the system claim:

`source exercises = 16`

Source preservation and teacher-added content are separate concepts.

Audit whether current schema can distinguish this reliably.

If it cannot, report the limitation as:

`OUT-OF-SCOPE / FUTURE PROVENANCE IMPROVEMENT`

unless it blocks the invariant.

Do not build a new provenance subsystem without evidence it is required.
