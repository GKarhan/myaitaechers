1. PRODUCT RULE — AUTHORITATIVE
══════════════════════════════════════

Normal lesson/node quiz generation must assess each selected MicroNode at ONLY its canonical target Cognitive Level.

Examples:

MicroNode path:
Remember → Understand → Apply[target]

Normal quiz target:
Apply ONLY.

Do NOT automatically generate:
Remember questions,
Understand questions,
and Apply questions.

Another MicroNode:

Understand[target]

Normal quiz target:
Understand ONLY.

Another:

Remember → Understand → Analyze[target]

Normal quiz target:
Analyze ONLY.

The lower Cognitive Path levels are primarily used by AI Teacher during teaching/scaffolding/micro-check progression.

The normal assessment quiz tests whether the learner has reached the MicroNode's canonical target.

This distinction is intentional:

AI Teacher:
may traverse the Cognitive Path level by level.

Normal Quiz:
assesses the canonical target level.

5. MULTI-MICRONODE QUIZZES
══════════════════════════════════════

A quiz may contain several selected MicroNodes with different targets.

Example:

Node A → Understand
Node B → Apply
Node C → Analyze
Node D → Apply

The generation scope must preserve this per-node target information.

It must NOT collapse the whole quiz into one global Bloom level.

[

  },

    microNodeId: B,
    targetCognitiveLevel: apply
  },
  {
    microNodeId: C,
    targetCognitiveLevel: analyze
  },
  {
    microNodeId: D,
    targetCognitiveLevel: apply
  }
]

Use the existing project types/naming conventions rather than inventing these exact names if equivalent canonical types already exist.

6. QUESTION GENERATION SEMANTICS
══════════════════════════════════════

The provider prompt must receive the target Cognitive Level for the specific MicroNode being assessed.

The generated question must require the cognitive operation represented by that level.

Important:

Question FORMAT does not equal Bloom level.

For example:

multiple_choice ≠ Remember

A multiple-choice question may test Understand or Analyze if the cognitive task genuinely requires that operation.

Likewise:

short_answer ≠ automatically Understand
problem_solving ≠ automatically Apply

The target Cognitive Level defines the required cognitive operation.

The interaction/question format is a separate dimension.

Use the existing Cognitive Path data, including preferredInteractionTypes where already authoritative and applicable.

Do NOT invent a new question-format taxonomy in T7.1.
