# Phase 7 — Dependencies

Dependencies-ը բաժանիր երկու մակարդակի։

## Level 1 — Deterministic dependencies

Եթե MicroNode-ների կառուցվածքից ակնհայտ է հաջորդականությունը, dependency-ն կարող է ստեղծվել deterministic logic-ով։

Օրինակ՝

`MN1 → MN2 → MN3`

եթե դա բխում է դասի/թեմայի հաստատված կառուցվածքից։

Դրա համար **AI call չօգտագործել**։

Նախ ուսումնասիրիր՝ ներկայիս system-ում արդյոք արդեն կա dependency-related field/table/logic։

---

## Level 2 — Semantic dependencies

Եթե dependency-ն չի բխում պարզապես sequence-ից, այլ պահանջում է բովանդակային իմաստային դատողություն, օրինակ՝

`fractions → equivalent fractions → adding fractions`

ապա հետագայում կարող է լինել AI-assisted dependency analysis։

Բայց սա **առաջին iteration-ում պարտադիր չէ**։

Առաջին iteration-ի նպատակն է ունենալ պարզ, վերահսկելի և deterministic dependency layer։

# Կարևոր Architecture Rule

**Phase 2 — Teaching Enrichment**
↓

# Exercise Mapping — նույնպես հաշվի առ

Նախորդ աշխատանքից կարևոր պահանջ կա.

Բոլոր իրական `EXERCISE / ACTIVITY / HOMEWORK` source blocks-ը պետք է պահպանվեն։

Յուրաքանչյուր exercise պետք է լինի կամ.

### A. կապված MicroNode-ի հետ

`MicroNode → exercises[]`

կամ

### B. չկապված՝ Additional Exercises

`Topic → additionalExercises[]`

**Ոչ մի exercise չպետք է կորի։**

Teacher Review/UI-ում պետք է հնարավոր լինի ձեռքով փոխել exercise-ի owner-ը՝

`MicroNode A → MicroNode B`

կամ

`MicroNode → Additional Exercises`

կամ հակառակը։

Այսինքն exercise assignment-ը պետք է լինի **editable**, ոչ թե irreversible AI decision։
