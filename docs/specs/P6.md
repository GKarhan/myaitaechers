  - Error Severity ≠ CRITICAL
  - No unresolved errors
7.2. Supporting Node Outcome
text
Supporting Node → MASTERED
IF:
  - Evidence Quality ≥ MODERATE
  - Target Bloom ապացուցված է
  - Support Level ≤ 2
7.3. Extension Node Outcome
text
Extension Node → MASTERED
IF:
  - Evidence Quality ≥ MODERATE
  - Target Bloom ապացուցված է
  - Time budget-ը բավարար է
7.4. Node with Unresolved Errors
text
Node → REPAIR_NEEDED
IF:
  - Error Severity = CRITICAL
  - Error Stability = PERSISTENT
  - Core Node
7.5. Review Needed
text
Node → REVIEW_NEEDED
IF:
  - Evidence Quality = MODERATE
  - Error Stability = REPEATED
  - Long time since last review
7.6. Partial Completion Rule (ՆՈՐ)
text
Node → PARTIALLY_COMPLETED
IF:
  - Evidence Quality = MODERATE
  - Target Bloom partially demonstrated
  - Time budget expired
  - Session interrupted
