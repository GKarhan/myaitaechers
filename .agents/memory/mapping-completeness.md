---
name: Mapping completeness and learner-state merges
description: Safety rules for independent assessability, canonical consolidation, and deterministic post-canonical repair.
---

Two candidates may be automatically merged only when semantic review explicitly certifies that one observable success criterion proves both objectives (`SAME` learner-state relation). Directional transformations are not assumed identical: if learners can demonstrate one direction without the other, retain separate targets. Independent targets derive from every source-backed pre-promotion candidate, even when its concept tokens are empty; exercise, outcome, and goal evidence can annotate a target but never create one.

**Why:** Similar wording, shared source material, or reverse operations can conceal independently assessable knowledge. A missing certification must fail closed to teacher review instead of collapsing a candidate.

**How to apply:** Run the deterministic completeness audit after canonicalization and before persistence. Target grouping requires the same performance direction—an unspecified candidate must never bridge opposite explicit directions. Coverage requires the exact canonical candidate or an explicit `SAME` group with the same direction, never lexical overlap alone. Restore only the exact pre-canonical candidate when each core source is unowned except for transferable review-safe unmapped placement and every linked activity is unowned; never steal source, supporting, or activity ownership, fabricate from an exercise/outcome, or restore an intentionally review-held candidate. Source conflicts and unresolved exercise/outcome demand remain structured review findings.
