---
name: Mapping completeness and learner-state merges
description: Safety rules for independent assessability, canonical consolidation, and deterministic post-canonical repair.
---

Two candidates may be automatically merged only when semantic review explicitly certifies that one observable success criterion proves both objectives (`SAME` learner-state relation). Directional transformations are not assumed identical: if learners can demonstrate one direction without the other, retain separate targets.

**Why:** Similar wording, shared source material, or reverse operations can conceal independently assessable knowledge. A missing certification must fail closed to teacher review instead of collapsing a candidate.

**How to apply:** Run the deterministic completeness audit after canonicalization and before persistence. It may restore only the exact pre-canonical candidate when every core source remains exclusively available. Never fabricate a node from an exercise or outcome, duplicate/steal source ownership, or restore an intentionally review-held candidate. Source conflicts and unresolved exercise/outcome demand remain structured review findings.
