## What it is
`runPass2Pipeline(blocks, lessonInfo)` in `artifacts/api-server/src/services/lesson-mapping.ts`.
Models: Step 1 = `deepseek/deepseek-chat`, Step 2 = `google/gemini-2.5-flash`.

## Key design decision
`sourceBlockIndices` is described as "all owned non-exercise non-image blocks" — NOT "theory blocks". This prevents the model from creating exercise-only MicroNodes (the v2 failure). The few-shot CORRECT/WRONG example in PASS2_STEP2_SYSTEM explicitly names "Exercises on Nouns" with empty sourceBlockIndices as illegal.

**Why:** v2 prompt used "theory blocks" framing → model logically created theory+exercise paired MicroNodes where the exercise one had empty sourceBlockIndices. Coverage rule encouraged the split.

## Size-cap guard
`PASS2_MAX_GROUP_SIZE = 20`. After Step 1 grouping, any group > 20 blocks triggers `subdivideGroup()` (same Step 1 model, same system prompt variant). Without this, a 45-block group in lesson 68 produced oversized MicroNodes with src/ex role confusion.

**Why:** Step 2 calls see ≤20 blocks each, making enumeration reliable within the context of one call.

## Route
`POST /lessons/:lessonId/map` (requireTeacher) now runs full Pass 1 + Pass 2.
- Pass 1 runs in-memory (no DB write).
- Pass 2 runs on in-memory blocks using 0-based array indices (not DB IDs).
- DB writes happen only after both passes complete: delete old topics/nodes/exercises, then insert topics → MicroNodes → exercises in sequence.

## Storage schema
- `lesson_topics`: one row per topic (lessonId, title, sequence)
- `lesson_nodes`: one row per MicroNode (topicId FK, learningObjective, microNodeType, theoryContent = joined source block texts, verbatimTheoryAnchor = same)
- `lesson_exercises`: one row per exercise block (exerciseId = EX-{lessonId}-{N}, relatedNodeId FK → MicroNode)

## Validated results
- Lesson 68 (85 blocks, 8 pages): 85/85 coverage, 0 empty sourceBlockIndices, 7 topics, 10 MicroNodes, 21 exercises. No hallucinated topics.
- Lesson 60 (32 blocks, 4 pages, fresh content): 32/32 coverage, 0 empty sourceBlockIndices, 4 topics, 6 MicroNodes, 4 exercises. No hallucinated topics.
