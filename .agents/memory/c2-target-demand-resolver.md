---
name: C2 target-demand resolver
description: C2 target selection policy and the safe relationship between C1 Bloom values and generated Cognitive Paths.
---

Resolve one C2 target cognitive demand from the MicroNode objective, verified theory/source, linked source exercises, approved aligned outcomes, title context, and the persisted C1 Bloom value. The decision has a target level, confidence, safe reason codes, C1 relation, review reasons, and a contract version; it never stores model reasoning.

**Why:** The persisted C1 Bloom value can be stale or underspecified. Treating it as a hard ceiling can suppress independently assessable source-supported application, analysis, evaluation, or creation. Conversely, unresolved disagreements must not produce a plausible-looking path.

**How to apply:** C1 is a prior/discrepancy signal only. A generated path's target ceiling must match the server-resolved demand exactly, while all structural, Armenian-content, interaction, objective-floor, source-grounding, and persistence gates remain unchanged. Low confidence, objective/source disagreement, uncorroborated stronger source evidence, or any disagreeing approved aligned outcome must fail closed to teacher review. Strong exercise evidence only corroborates the same target level, never an unrelated higher source claim.
